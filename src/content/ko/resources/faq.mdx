## 도입

### Specify는 어떤 팀에 맞나요?

문서를 쓸 시간과 인력이 부족한 개발팀에 맞습니다. 특히 Claude Code·Cursor·Codex 같은 AI 도구를 일상적으로 쓰는 팀이라면 문서 자동화와 MCP 연결을 함께 활용할 수 있습니다.

### 기존 도구를 바꿔야 하나요?

아니요. 기존 GitHub와 에디터 워크플로를 유지한 채 GitHub 연결만 추가하면 됩니다. 문서 하나로 파일럿을 시작해 볼 수 있습니다.

### 팀원도 설정해야 하나요?

팀원은 초대를 수락하면 됩니다. 문서를 읽거나 AI에게 질문하는 데 별도 설정이 필요하지 않습니다.

## 문서 자동화

### AI가 문서를 마음대로 바꾸지 않나요?

새 프로젝트는 자동 반영 없이 시작합니다. 코드 변경에 따른 문서 변경은 근거와 수정 전후를 담은 수정안으로 먼저 도착하고, 이후 반영 방식은 프로젝트 설정과 적용 정책을 따릅니다. 자동 반영이 허용된 경우에는 저위험 변경이 자동 승인될 수 있습니다.

### 코드가 바뀌면 문서가 자동으로 갱신되나요?

소스에 **push 시 실행**이 켜져 있고 문서 스킬이 증분 갱신 방식이라면, 선택한 브랜치에 코드가 반영될 때 수정안이 준비됩니다. 전체 재생성 방식의 문서는 필요할 때 다시 생성해야 합니다.

### 무료 플랜에서도 문서 자동화를 쓸 수 있나요?

문서 프로젝트(GitHub 기반 문서 생성과 자동 최신화)는 프로·맥스·팀·엔터프라이즈 플랜 기능입니다. 무료 플랜에서는 문서 작성, AI 채팅, 워크스페이스 RAG를 사용할 수 있습니다.

### 조직 저장소도 연결할 수 있나요?

네. 조직 저장소는 GitHub 조직 관리자가 요청을 승인한 뒤 연결됩니다. 승인 후 Specify에서 다시 연결을 눌러 완료하세요.

## 보안

### 우리 코드와 문서는 안전한가요?

모든 데이터는 AWS 인프라에서 워크스페이스 단위로 격리되어 운영되며, 승인된 멤버에게만 노출됩니다. 고객 데이터를 AI 모델 학습에 사용하지 않습니다. 자세한 내용은 [보안과 데이터](/ko/resources/security)를 참고하세요.

## AI와 모델

### 어떤 모델을 쓰면 되나요?

일상적인 문서 작성·수정은 기본 모델인 GPT-6 Luna로 시작하세요. 문장·표·여러 문서의 지정 부분을 고치는 작업에는 Claude Haiku 5.5도 활용할 수 있습니다. 더 빠른 응답이나 다른 구성이 필요할 때 같은 요청으로 다른 모델을 비교하세요. 작업별 선택 기준과 도구 호출·편집 성능은 [모델 선택 가이드](/ko/models/choosing)를 참고하세요.

### AI는 무엇을 근거로 답하나요?

워크스페이스 RAG로 팀의 문서, 업로드한 파일, 연동한 Slack 공개 채널 메시지를 검색해 근거로 삼고, 근거가 된 문서를 링크로 보여 줍니다. 검색은 내가 멤버인 워크스페이스 안에서만 동작합니다. [워크스페이스 RAG](/ko/knowledge/rag)를 참고하세요.

### 규제 문서도 정확하게 쓸 수 있나요?

표준 문서 라이브러리를 사용할 수 있는 워크스페이스에서는 에이전트가 IEC 62304, ISO 14971 등의 조항을 검색해 인용하며 씁니다. 근거가 없는 내용은 `[GAP]`으로 표시합니다. 생성된 문서는 제출 전 전문가 검토가 필요한 초안입니다. [표준 문서 라이브러리](/ko/knowledge/standards)를 참고하세요.

## MCP

### 어떤 코딩 에이전트를 연결할 수 있나요?

Claude Code, Codex, Cursor, VS Code, Claude Desktop을 포함해 MCP를 지원하는 클라이언트라면 연결할 수 있습니다. [에디터·에이전트 연결](/ko/mcp/connect)을 참고하세요.

### 에이전트가 문서를 수정할 수도 있나요?

토큰을 발급할 때 **문서 생성·수정 허용**을 체크하면 가능합니다. 기본은 읽기 전용이며, 관리자는 워크스페이스 정책으로 생성·편집을 막을 수 있습니다.

## 요금

네. 무료 플랜은 신용카드 없이 시작할 수 있고, 프로·팀 플랜은 14일 무료 체험을 제공합니다. 최신 요금은 [요금제 페이지](https://specify.app/ko/pricing)를 확인하세요.
