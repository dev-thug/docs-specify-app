## 시작하기

### 어떤 자료로 시작하나요?

워크스페이스에 문서를 쓰거나 파일을 올리고, 채팅에서 필요한 자료를 지정해 질문하세요. GitHub·Notion·Slack 같은 외부 서비스는 연결한 뒤 필요할 때 검색합니다.

### 팀원도 설정해야 하나요?

팀원은 자신의 계정으로 초대를 수락합니다. 외부 에디터를 연결하려면 각자 MCP 접근 권한을 발급해야 합니다.

## 문서 자동화

### 코드 변경은 어떻게 반영되나요?

문서나 캔버스에 GitHub 저장소와 브랜치를 연결하면 해당 브랜치의 push를 계기로 기존 항목을 갱신합니다. 현재 본문과 최신 소스를 읽고 필요한 변경을 저장합니다. 완료 후 저장된 내용과 변경 기록에서 갱신 결과를 확인할 수 있습니다.

### 자동 갱신 뒤에 무엇을 확인하나요?

인박스와 실행 결과를 보고 실제 문서의 변경 내용을 확인하세요. 관련 없는 설명이 유지됐는지, 변경된 값과 삭제된 기능이 맞게 반영됐는지, 인용이 정확한지 검토합니다. [문서 자동화](/ko/guides/review-proposals)를 참고하세요.

## AI와 지식 검색

### 어떤 모델을 쓰면 되나요?

짧은 작업으로 같은 자료와 요청을 비교하고 사실, 누락, 저장 결과, 사용량을 확인하세요. [모델 선택 가이드](/ko/models/choosing)를 참고하세요.

### 필요한 자료를 검색에서 찾으려면 어떻게 하나요?

문서 이름이나 고유한 용어로 검색하고, 문서 목록과 원문도 확인하세요. 저장이나 업로드 직후에는 색인 처리 상태를 확인한 뒤 다시 검색합니다. 외부 서비스 자료는 워크스페이스 색인과 별도의 커넥터 검색을 사용합니다. [워크스페이스 RAG](/ko/knowledge/rag)를 참고하세요.

### 표준을 인용하면 제출 가능한 문서인가요?

표준 인용으로 근거를 확인하고, 전문가와 조항·판·규범성·제품별 근거를 검토해 제출 자료를 완성하세요. 규제 적합성과 인증은 해당 평가 절차에서 확인합니다. [표준 문서 라이브러리](/ko/knowledge/standards)를 참고하세요.

## MCP와 이용 요금

### MCP로 무엇을 하나요?

Claude Code·Codex 등 외부 에이전트가 워크스페이스 맥락을 검색하고 읽습니다. 쓰기 권한과 적절한 역할을 허용하면 문서나 캔버스도 수정할 수 있습니다. [제공 도구](/ko/mcp/tools)를 참고하세요.

### 요금과 지원은 어디서 확인하나요?

최신 조건은 [요금제 페이지](https://specify.app/pricing), 문의는 [support@specify.app](mailto:support@specify.app)을 이용하세요.
