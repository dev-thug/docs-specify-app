워크스페이스의 자료와 외부 도구 연결을 관리할 때 접근 범위와 권한을 함께 확인하세요.

## 워크스페이스와 역할

자료 접근은 현재 워크스페이스와 멤버십, 역할을 기준으로 처리합니다. 워크스페이스를 바꿔 작업할 때 대상이 맞는지 확인하세요. 역할에 관한 설명은 [팀 초대와 권한](/ko/workspace/members)을 참고하세요.

## 외부 서비스 연결

연결한 GitHub·Notion·Slack 같은 서비스는 허용된 계정과 리소스 범위에서 사용합니다. 외부 서비스 자료는 워크스페이스 지식 색인에 복제하는 대신 커넥터로 검색합니다. 연결이 필요 없으면 해제하고, 서비스 쪽 권한도 점검하세요.

## MCP 접근

외부 클라이언트는 MCP 토큰 또는 OAuth로 인증합니다. 기본은 읽기 전용이며, 쓰기에는 별도 범위와 적절한 워크스페이스 역할이 필요합니다. 토큰을 공유 문서나 저장소에 보관하지 마세요.

MCP에서 제외한 문서·폴더와 하위 자료는 외부 에이전트 접근 대상에서 제외됩니다. 관리자는 외부 접근과 도구 사용 정책을 관리할 수 있습니다. [토큰과 접근 정책](/ko/mcp/access)을 참고하세요.

## 데이터 처리와 문의

데이터 처리 조건은 [개인정보 처리방침](https://specify.app/ko/privacy)을 확인하세요. 보안 문의나 취약점 제보는 [support@specify.app](mailto:support@specify.app)으로 보내 주세요.
