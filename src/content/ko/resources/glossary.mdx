Specify의 주요 용어를 설명합니다.

## 자료와 작업

| 용어 | 뜻 |
| --- | --- |
| 워크스페이스 | 문서, 대화, 멤버와 연결 도구를 공유하는 작업 범위입니다. |
| 문서 | 저장하고 편집하며 변경 기록을 확인할 수 있는 텍스트 자료입니다. |
| 캔버스 | 요소와 연결로 구조나 아키텍처를 표현하는 자료입니다. |
| 저장소 연결 | 문서·캔버스와 GitHub 저장소·브랜치를 연결해 코드 변경을 반영하는 설정입니다. |
| 자동 갱신 | 연결된 브랜치의 push를 계기로 기존 문서나 캔버스를 최신 소스와 맞추는 작업입니다. |
| 인박스 | 백그라운드 작업의 진행 상황과 결과를 확인하는 곳입니다. |
| 스레드 | 에이전트와 나누는 대화의 단위입니다. |

## 지식과 도구

| 용어 | 뜻 |
| --- | --- |
| RAG | 검색한 자료를 근거로 답변을 만드는 검색 증강 생성입니다. |
| 색인 | 문서와 파일에서 검색 가능한 자료를 준비하는 처리입니다. |
| 표준 문서 라이브러리 | 표준의 조항과 판을 근거로 검색하는 지식 소스입니다. |
| 스킬 | 에이전트가 특정 작업을 수행할 때 따르는 지침입니다. |
| 커넥터 | GitHub, Notion, Slack 같은 외부 서비스에 연결하는 기능입니다. |
| MCP | 외부 AI 클라이언트가 도구와 자료를 사용하는 연결 규약입니다. |
| MCP 토큰 | 외부 클라이언트가 워크스페이스에 접근할 때 사용하는 인증 정보입니다. 기본은 읽기 전용입니다. |
| 리비전 | 읽거나 수정한 문서·캔버스의 버전입니다. 쓰기 충돌 확인에 사용합니다. |
| 사고 강도 | 모델의 추론 수준을 조절하는 설정입니다. 지원 단계는 모델과 플랜에 따라 달라집니다. |
| [GAP] | 추가 근거나 사람의 확인이 필요한 부분을 표시하는 표기입니다. |
