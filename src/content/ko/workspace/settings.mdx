계정 메뉴의 **설정**에서 계정, 워크스페이스, 도구, 사용량을 관리합니다. 보이는 항목은 현재 워크스페이스와 권한에 따라 달라집니다.

## 설정 항목

| 그룹 | 항목 | 내용 |
| --- | --- | --- |
| 계정 | 일반 · 알림 | 프로필, 테마, 언어, 알림 설정 |
| 워크스페이스 | 일반 · 멤버 | 이름, 설명, URL, 기본 AI 모델, 팀 멤버 관리 |
| AI 에이전트 | 도구와 스킬 | 스킬, 외부 서비스 연결, 에디터 MCP 연결 |
| 사용 권한 및 청구 | 요금제 · 사용량 | 현재 플랜, 결제, AI 사용량 |
| 관리 | 보관함 | 보관한 채팅과 인박스 항목 검색·복원·삭제 |

팀 멤버를 관리하려면 팀 워크스페이스에서 멤버 항목을 여세요.

## 워크스페이스 일반

이름과 설명을 수정하고 워크스페이스 URL을 관리합니다. **기본 AI 모델**은 워크스페이스 자동화의 기본 모델입니다. 채팅의 모델 선택과 구분해서 확인하세요. [모델 개요](/ko/models/overview)를 참고하세요.

워크스페이스 삭제와 소유권 이전은 권한이 필요한 작업입니다. 소유권 이전 요청은 대상 멤버가 수락해야 완료됩니다.

## 도구와 스킬

스킬의 작업 지침, AI가 사용하는 외부 서비스, 외부 에디터의 접근 권한을 관리합니다. 외부 서비스 연결과 MCP 에디터 연결은 목적이 다릅니다. MCP는 외부 에이전트가 Specify 자료를 검색하고 읽는 연결입니다.

[도구와 스킬](/ko/guides/plugins-skills), [에디터 연결](/ko/mcp/connect)을 참고하세요.

## 사용량과 보관함

사용량은 현재 워크스페이스 기준입니다. [사용량과 AI 예산](/ko/models/usage)에서 확인 방법을 설명합니다.

보관함에서 채팅이나 인박스 항목을 복원할 수 있습니다. 인박스 항목을 삭제해도 생성된 문서와 실행 기록은 유지됩니다. 문서 휴지통과는 별도입니다.
