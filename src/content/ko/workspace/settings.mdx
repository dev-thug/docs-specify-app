설정은 사이드바 맨 아래 **계정 메뉴** → **설정**에서 엽니다. 설정 창은 왼쪽 목록에서 항목을 고르면 오른쪽에 내용이 표시됩니다.

<Screenshot name="settings-general" alt="설정 창의 계정 일반 화면. 왼쪽에 계정, 워크스페이스, AI 에이전트, 사용 권한 및 청구, 관리 그룹이 있다" />

## 설정 항목

| 그룹 | 항목 | 할 수 있는 일 |
| --- | --- | --- |
| **계정** | 일반 | 프로필(이름·사진), 테마와 언어, 계정 탈퇴 |
| | 알림 | 알림 받기 설정 |
| **워크스페이스** | 일반 | 워크스페이스 이름·URL·설명, 기본 AI 모델, 문서 생성 모델 |
| | 멤버 · 팀 관리 | 팀 워크스페이스에서 멤버 초대와 역할 관리 ([팀 초대와 권한](/ko/workspace/members)) |
| **AI 에이전트** | 자동화 | 일정에 따라 실행되는 에이전트 작업 ([자동화 루틴](/ko/guides/automations)) |
| | 에이전트 학습 | 에이전트가 대화에서 학습한 메모리와 스킬 확인·삭제 |
| | 문서 스타일 가이드 | 워크스페이스 전체 문서에 적용할 작성 규칙 |
| | 플러그인 | 공식 스킬 플러그인 설치 ([플러그인과 스킬](/ko/guides/plugins-skills)) |
| | 도구와 스킬 | 커넥터, 스킬, 에디터 연결(MCP) 관리 |
| **사용 권한 및 청구** | 요금제 | 현재 플랜과 결제 관리 |
| | 사용량 | 이번 달 문서·AI 예산 사용량 ([사용량과 AI 예산](/ko/models/usage)) |
| **관리** | 보관함 | 보관한 항목 검색·복원·삭제 |

<Note>
  멤버와 팀 관리 항목은 팀 워크스페이스에서만 보입니다. 개인 워크스페이스에는 표시되지 않습니다.
</Note>

## 워크스페이스 일반

워크스페이스 이름과 URL, 그리고 이 워크스페이스에서 AI가 기본으로 쓸 모델을 정합니다.

<Screenshot name="settings-workspace" alt="워크스페이스 일반 설정. 조직 이름, 워크스페이스 URL, 설명, 기본 AI 모델, 문서 생성 모델 선택 상자가 있다" />

- **기본 AI 모델** — 이 워크스페이스의 자동화에서 사용할 기본 모델입니다.
- **문서 생성 모델** — 문서 자동화(프로젝트 생성·자동 갱신)에 사용할 모델입니다.
- 워크스페이스 URL의 식별자(slug)는 영문, 숫자, 하이픈만 쓸 수 있습니다. UUID 주소로는 언제나 접근할 수 있습니다.

어떤 모델을 고르면 좋은지는 [모델 선택 가이드](/ko/models/choosing)를 참고하세요.

## 문서 스타일 가이드

워크스페이스가 생성하는 모든 문서에 공통으로 적용되는 작성 규칙입니다. 문체, 구성, 용어를 마크다운으로 적으면 다음 생성부터 반영됩니다.

<Screenshot name="settings-style-guide" alt="문서 스타일 가이드 설정. 마크다운으로 문체와 구성 규칙을 입력하는 칸과 저장 버튼이 있다" />

- 최대 8,192바이트까지 입력할 수 있습니다.
- 길이·인용·검증 같은 시스템 품질 기준은 여기서 완화할 수 없습니다.
- 문서 프로젝트마다 더 구체적인 [프로젝트 스타일 가이드](/ko/guides/automation-settings)를 둘 수 있고, 충돌하면 프로젝트 가이드가 우선합니다.
- 편집자 이상 권한이 필요합니다.

## 사용량

이번 달 문서 수와 AI 예산 사용률을 확인합니다. 사용량은 현재 워크스페이스 기준이며 개인·팀 워크스페이스 예산은 서로 별개입니다.

AI 예산이 계산되는 방식은 [사용량과 AI 예산](/ko/models/usage)을 참고하세요.
