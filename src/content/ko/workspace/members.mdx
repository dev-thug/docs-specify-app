팀원은 자신의 계정으로 초대를 수락해 워크스페이스에 참여합니다.

## 역할

| 역할 | 범위 |
| --- | --- |
| 소유자 | 워크스페이스의 소유권과 관리 권한을 가집니다. |
| 관리자 | 멤버와 워크스페이스 설정을 관리합니다. |
| 편집자 | 허용된 문서와 캔버스를 편집합니다. |
| 뷰어 | 허용된 자료를 읽습니다. |

## 초대와 관리

**설정** → **워크스페이스** → **멤버**에서 **멤버 초대**를 선택합니다. 이메일과 역할을 정하고 **초대 보내기**를 누릅니다. 초대받은 이메일의 계정으로 수락해야 합니다.

멤버 목록에서 권한이 허용하는 역할 변경, 일시정지, 제거 작업을 수행합니다. 대기 중인 초대는 재발송하거나 취소할 수 있습니다.

## 팀과 개인 워크스페이스

팀원을 초대하고 역할을 관리하려면 팀 워크스페이스의 멤버 설정을 여세요. 개인 워크스페이스는 개인 작업에 사용합니다. 플랜별 이용 조건과 한도는 [요금제 페이지](https://specify.app/pricing)를 확인하세요.

## 외부 에이전트 접근

외부 에디터 연결은 각 멤버의 접근 권한으로 사용합니다. MCP로 쓰기 작업을 하려면 편집자 이상 역할과 토큰의 쓰기 범위를 함께 확인하세요. [토큰과 접근 정책](/ko/mcp/access)을 참고하세요.
