Specify에서는 사이드바에서 자료와 대화를 찾고, 가운데 탭에서 문서와 채팅을 엽니다. 문서와 캔버스를 대화와 함께 사용해 팀 지식을 정리할 수 있습니다.

## 사이드바와 검색

사이드바에서 문서, 채팅, 인박스를 탐색합니다. **검색** 또는 <Kbd>⌘K</Kbd>로 커맨드 팔레트를 열어 문서를 찾거나 명령을 실행합니다.

문서와 폴더는 탐색기에서 정리합니다. 삭제한 자료는 휴지통에서 복원할 수 있습니다. 맨 아래 계정 메뉴에서는 워크스페이스를 전환하거나 설정을 엽니다.

## 새로 만들기

사이드바의 **신규** 메뉴에서 다음 작업을 시작합니다.

- **새 문서** — 빈 문서를 만들고 편집합니다.
- **새 채팅** — AI와 새 대화를 시작합니다.
- **자료 추가** — 파일을 올려 워크스페이스 자료로 사용합니다.

GitHub 코드를 문서로 만들려면 채팅에서 저장소와 원하는 문서를 지정하세요. 만든 문서나 캔버스에 저장소를 연결하면 코드 변경에 따른 자동 갱신을 사용할 수 있습니다.

## 문서와 채팅 탭

여러 문서와 대화를 탭으로 열고 오가며 작업합니다. 채팅에서는 모델과 사고 강도를 선택하고 필요한 자료를 지정합니다. [문서 편집](/ko/guides/editor)과 [AI 채팅](/ko/guides/ask-ai)을 참고하세요.

## 인박스와 결과 확인

인박스에서 백그라운드 작업의 진행 상황과 결과를 확인합니다. 실행이 끝나면 결과 요약뿐 아니라 실제 문서와 캔버스를 열어 변경 내용을 확인하세요.

개인 환경과 팀 환경을 오갈 때는 현재 워크스페이스를 먼저 확인하세요. 멤버와 도구 연결은 [설정](/ko/workspace/settings)에서 관리합니다.
