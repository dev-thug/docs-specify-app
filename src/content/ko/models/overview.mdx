Specify는 Anthropic Claude와 OpenAI GPT 계열의 모델 6종을 제공합니다. 채팅 입력창에서 대화마다 모델을 고르고, 워크스페이스 설정에서 자동화에 쓸 기본 모델을 정합니다.


<Screenshot name="model-picker" alt="지원 모델 6종이 표시된 모델 선택 메뉴" caption="채팅 입력창의 모델 버튼 → 모델에서 선택합니다. 체크 표시는 현재 모델입니다." />

## 모델 비교

| 모델 | 제공사 | 사용 가능 플랜 | 컨텍스트 | 최대 출력 |
| --- | --- | --- | --- | --- |
| **Claude Opus 5.5** | Anthropic | 프로 이상 | 100만 | 128K |
| **Claude Sonnet 5.5** | Anthropic | 프로 이상 | 100만 | 128K |
| **Claude Haiku 5.5** | Anthropic | 무료 포함 전체 | 100만 | 128K |
| **GPT-6.1 Sol** | OpenAI | 프로 이상 | 105만 | 128K |
| **GPT-6.1 Terra** | OpenAI | 프로 이상 | 105만 | 128K |
| **GPT-6 Luna** | OpenAI | 무료 포함 전체 | 105만 | 128K |

모든 지원 모델은 **100만 토큰 이상의 컨텍스트**를 제공합니다. Claude는 100만, GPT는 105만 토큰입니다. 컨텍스트는 한 번의 요청에서 다루는 대화·자료의 범위이며, 최대 출력 토큰 수와는 별개입니다.

- 최신 요금과 한도는 [요금제 페이지](https://specify.app/pricing), 사용량 계산 방식은 [사용량과 AI 예산](/ko/models/usage)을 참고하세요.
- 모든 모델이 도구 호출(자료 검색, 문서 읽기·쓰기 등)과 병렬 도구 호출을 지원합니다.
- 새 대화의 기본 모델은 **Claude Haiku 5.5**입니다.

## 모델별 특징

같은 자료와 요청으로 실제 결과의 정확도와 속도를 비교하세요. 작업에 맞는 모델은 결과의 완성도와 사용량을 함께 보고 선택합니다.

작업별로 어떤 모델을 쓰면 좋은지는 [모델 선택 가이드](/ko/models/choosing)에서 자세히 설명합니다.

## 사고 강도

**사고 강도**를 **끄기**, **낮음**, **보통**, **높음**, **엑스트라**, **최대** 여섯 단계로 조절할 수 있습니다. Claude Opus 5.5와 GPT-6.1 Sol은 낮음부터 최대까지 다섯 단계를 지원합니다. 강도를 높이면 답하기 전에 더 깊이 추론하지만 응답이 느려지고 토큰을 더 씁니다.

<Note>
  무료 플랜에서는 사고 강도가 **끄기**로 고정됩니다. 모델을 바꾸면 현재 사고 강도는 새 모델이 지원하는 범위로 맞춰집니다.
</Note>

## 모델을 고르는 곳

| 위치 | 적용 범위 |
| --- | --- |
| 채팅 입력창의 모델 버튼 | 현재 대화 전체. 응답이 끝나면 변경할 수 있습니다. |
| **설정** → **워크스페이스** → **일반** → **기본 AI 모델** | 이 워크스페이스의 자동화 |

플랜에서 쓸 수 없는 모델은 메뉴에 자물쇠로 표시되며, 선택하면 플랜 업그레이드 안내가 나옵니다. 선택한 모델이 요청에 사용됩니다.

## 모델·스킬·플러그인·커넥터 이해하기

모델을 고른 뒤에는 **어떤 자료를 읽고, 어떤 방식으로 작업할지** 정합니다. 같은 모델에서도 연결한 자료와 스킬에 따라 결과가 달라집니다.

| 구성 | 역할 | 맘마(육아 앱)에서의 예 |
| --- | --- | --- |
| **모델** | 요청을 이해하고, 자료를 바탕으로 추론하고 답을 만듭니다. | Claude Haiku 5.5로 기록 저장 흐름을 정리합니다. |
| **스킬** | 반복 작업에 사용할 지침과 검수 절차입니다. 기본 스킬은 항상 켜져 있고, 워크스페이스 스킬은 사용 여부를 관리합니다. | 코드 분석으로 호출 흐름을 조사하고 문서 작성 지침에 따라 결과를 저장합니다. |
| **플러그인·연동** | 외부 서비스나 MCP 서버의 기능을 에이전트가 발견하고 사용하도록 연결합니다. | GitHub 연결을 확인하고 분석에 필요한 저장소 접근을 준비합니다. |
| **커넥터** | 연동할 서비스의 계정 연결 상태와 내 AI 사용을 관리하는 화면입니다. | GitHub 카드에서 연결됨과 내 AI 사용 켜짐을 확인합니다. |

### 스킬 확인하기

계정 메뉴의 **스킬 및 커넥터**를 열면 **도구** 화면이 나타납니다. **스킬**에서 기본 지침을 살펴보고, 팀의 반복 작업은 새 스킬로 정리할 수 있습니다. 모델을 바꾼 뒤에도 작업에 필요한 스킬과 자료를 함께 확인하세요.

<Screenshot name="skills-library" alt="코드 분석을 검색한 스킬 화면" caption="기본 스킬의 역할과 워크스페이스 스킬의 사용 상태를 확인하세요." />

### 외부 자료 연결하기

**도구 → 커넥터**에서 서비스를 찾습니다. **연결됨**과 **내 AI 사용 켜짐**을 함께 확인하세요. Google은 Gmail·캘린더·드라이브를 하나의 카드에서 연결합니다. 외부 에디터가 Specify 자료를 읽게 하려면 **에디터 연결**의 MCP 안내를 따릅니다.

<Screenshot name="connectors-library" alt="GitHub로 검색한 커넥터 화면" caption="서비스 연결과 내 AI 사용은 각각 확인합니다." />

### 맘마로 따라 하기

1. 채팅 입력창에서 **Claude Haiku 5.5**를 선택합니다.
2. 커넥터에서 GitHub 연결과 맘마 저장소 접근 권한을 확인합니다.
3. “맘마의 기록 저장 흐름을 코드 근거와 함께 정리해 줘”처럼 자료와 원하는 결과를 지정합니다.
4. 응답의 근거 파일, 도구 실행 결과와 저장된 문서를 확인합니다.

자세한 설정은 [스킬 가이드](/ko/guides/plugins-skills), [커넥터 가이드](/ko/guides/connectors), [MCP 가이드](/ko/mcp/overview)를 참고하세요.
