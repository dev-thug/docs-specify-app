Specify는 Anthropic Claude와 OpenAI GPT 계열의 모델 6종을 제공합니다. 채팅 입력창에서 대화마다 모델을 고르고, 워크스페이스 설정에서 자동화와 문서 생성에 쓸 기본 모델을 정합니다.

| **Claude Opus 5.5** | Anthropic | 프로 이상 | 20만 | 128K |
| **Claude Sonnet 5.5** | Anthropic | 프로 이상 | 20만 | 128K |

| **GPT-6.1 Sol** | OpenAI | 프로 이상 | 105만 | 128K |

| **GPT-6 Luna** | OpenAI | 무료 포함 전체 | 105만 | 128K |

- 모든 모델이 도구 호출(자료 검색, 문서 읽기·쓰기 등)과 병렬 도구 호출을 지원합니다.
- 새 대화의 기본 모델은 **GPT-6 Luna**입니다.

## 사고 강도

**사고 강도**를 **끄기**, **낮음**, **보통**, **높음**, **엑스트라**, **최대** 여섯 단계로 조절할 수 있습니다. 단, Claude Opus 5.5와 GPT-6.1 Sol은 끄기를 지원하지 않아 낮음부터 다섯 단계입니다. 강도를 높이면 답하기 전에 더 깊이 추론하지만 응답이 느려지고 토큰을 더 씁니다.

<Note>
  무료 플랜에서는 사고 강도가 **끄기**로 고정됩니다. 모델을 바꾸면 현재 사고 강도는 새 모델이 지원하는 범위로 맞춰집니다.
</Note>

## 모델을 고르는 곳

| 위치 | 적용 범위 |
| --- | --- |
| 채팅 입력창의 모델 버튼 | 현재 대화 전체. 응답 중에는 바꿀 수 없습니다. |
| **설정** → **워크스페이스 일반** → **기본 AI 모델** | 이 워크스페이스의 자동화 |
| **설정** → **워크스페이스 일반** → **문서 생성 모델** | 문서 자동화(프로젝트 생성·자동 갱신) |

플랜에서 쓸 수 없는 모델은 메뉴에 자물쇠로 표시되며, 선택하면 플랜 업그레이드 안내가 나옵니다. 요청한 모델을 몰래 다른 모델로 바꾸지 않습니다.
