일상적인 문서 작성과 수정은 **GPT-6 Luna로 시작**하세요. 기존 문서의 문장·표·여러 곳을 고치는 작업에는 **Claude Haiku 5.5도 충분히 활용할 수 있습니다**. 처음부터 상위 모델을 고르기보다, 요청한 내용이 정확히 저장됐는지와 작업 시간이 적절한지를 보고 선택하세요.

| 문장 바꾸기, 표 수정, 여러 문서의 지정 부분 고치기 | **GPT-6 Luna · Claude Haiku 5.5** | 수정 위치와 원하는 결과가 명확하다면 두 모델부터 사용하세요. 두 모델 모두 해당 편집 작업을 완료했습니다. |
| 짧은 편집의 대기 시간을 줄이기 | **Claude Sonnet 5.5도 비교** | 측정된 정밀 편집의 중앙값은 약 11초였습니다. 같은 요청으로 체감 속도와 사용량을 비교하세요. |

| 다른 OpenAI 모델의 결과 확인 | **GPT-5.6 Terra** | 같은 자료와 요청으로 표현·구성·작업 시간을 비교할 때 선택할 수 있습니다. |

## 문서 작업 성능

2026년 10월 문서 작업 기록을 기준으로, 같은 생성·편집 요청에서 문서 읽기·생성·수정·탐색 도구가 성공 응답을 반환한 비율과 저장 결과를 비교했습니다. 정밀 편집은 **부분 수정, 표 수정, 여러 문서의 지정 부분 수정**을 뜻합니다.

| 모델 | 문서 도구 호출 성공률 | 정밀 편집 완료율 | 편집 시간 중앙값 |
| --- | --- | --- | --- |
| Claude Opus 5.5 | 100% | 100% | 약 21초 |
| Claude Sonnet 5.5 | 90.9% | 100% | 약 11초 |
| Claude Haiku 5.5 | 100% | 100% | 약 15초 |
| GPT-6.1 Sol | 100% | 100% | 약 20초 |
| GPT-5.6 Terra | 94.1% | 100% | 약 24초 |
| GPT-6 Luna | 100% | 100% | 약 17초 |

도구 호출 성공률은 **개별 호출이 정상 처리된 비율**이고, 편집 완료율은 **저장된 문서가 요청한 수정 조건을 충족한 비율**입니다. 호출 도중 오류가 나도 후속 처리로 편집을 완료할 수 있습니다. 시간은 편집 시작부터 실행 완료까지의 관측값이며, 문서 길이·검색 범위·서버 상태에 따라 달라집니다. 이 수치는 짧은 문서 작업의 관측치이며 모든 작업의 성공률을 보장하지 않습니다.

**작은 편집에서는 Luna와 Haiku로도 요청한 결과를 얻었습니다.** 상위 모델로 바꾸는 기준은 모델 이름보다 실제 결과의 누락, 근거의 정확성, 소요 시간입니다. 새 문서를 작성할 때에는 제공하지 않은 사실이 추가되지 않았는지 확인하세요.

## 모델을 바꿀 때

- **원하는 부분을 고치지 못했다면** 문서와 수정 위치를 지정하고, 바꿀 내용과 유지할 내용을 나누어 요청하세요. 그래도 결과가 부족하면 같은 요청으로 다른 모델을 비교합니다.
- **긴 문서의 구성이 부족하다면** 먼저 목차와 필수 항목을 정한 뒤 섹션별로 작성하게 하세요. 설명의 연결이나 분석이 부족할 때 Sonnet·Sol·Opus의 결과를 비교합니다.
- **코드 변경을 여러 문서에 반영한다면** 개요·레퍼런스·운영 문서의 값과 예시를 함께 확인하세요. 큰 모델도 전체 반영을 보장하지는 않습니다.
- **출처가 중요한 문서라면** 모델의 답변과 인용 원문을 대조하세요. 링크가 열리는지뿐 아니라 실제 설명을 뒷받침하는지 확인합니다.

## 사고 강도 고르기

짧은 초안과 지정 부분 수정은 **끄기** 또는 지원되는 낮은 단계에서 시작하세요. 여러 자료를 비교하거나 설명을 깊게 다뤄야 할 때 강도를 높여 결과를 비교합니다. 강도를 높이면 사용량과 시간이 늘 수 있습니다. 무료 플랜에서는 **끄기**로 고정됩니다.
