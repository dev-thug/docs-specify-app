모델은 작업 결과와 사용량을 함께 보고 고르세요. 같은 자료와 요청으로 비교하면 빠진 내용과 수정 정확도를 판단하기 쉽습니다.

## 작은 작업부터 비교하기

무료 플랜에서도 선택할 수 있는 **Claude Haiku 5.5**와 **GPT-6 Luna**로 짧은 초안이나 지정 부분 수정을 시작할 수 있습니다. 더 복잡한 자료를 다룬다면 사용 가능한 다른 모델과 결과를 비교하세요.

- 문서 이름, 바꿀 부분, 유지할 내용을 지정합니다.
- 사실, 인용 근거, 저장된 결과를 확인합니다.
- 결과가 부족하면 같은 요청으로 모델이나 사고 강도를 바꿔 비교합니다.

## 측정 결과의 범위

모델을 비교할 때에는 같은 모델 버전과 작업 조건의 측정값을 기준으로 삼으세요. 현재 모델 전체의 동일 조건 비교에는 추가 측정이 필요합니다. GPT-6.1 Terra는 이 안내에서 미측정입니다. 이전 GPT-5.6 Terra의 측정값은 해당 버전의 참고 자료로 활용하고, 현행 모델의 속도·정확도·비용은 실제 작업 결과로 비교하세요.

## 사고 강도 선택하기

지원되는 낮은 단계부터 시작하고, 여러 자료의 비교나 복잡한 설명이 필요할 때 높여 보세요. 무료 플랜은 **끄기**로 고정됩니다. Claude Opus 5.5와 GPT-6.1 Sol은 낮음부터 선택할 수 있습니다.

## 코드와 문서의 정합성 확인하기

저장소에 연결된 문서와 캔버스는 push 후 기존 항목에 변경이 반영될 수 있습니다. 자동 갱신 뒤에도 변경된 기본값, 삭제된 기능, 경로, 인용을 현재 코드와 대조하세요. 관련 없는 수동 작성 내용이 유지됐는지도 확인합니다.
