## 결과를 검토하는 공통 순서

1. <strong>범위를 정합니다.</strong> 자료 이름, 제품 버전, 대상 기간과 저장소 커밋을 지정합니다.
2. <strong>근거 원문을 확인합니다.</strong> 검색 결과만으로 단정하지 말고 원문을 엽니다. 검색되지 않으면 색인 상태와 접근 권한도 확인합니다.
3. <strong>검토하기 쉬운 형식으로 요청합니다.</strong> 표·비교표·안내문·체크리스트와 함께 출처 ID, 확인 상태, 미확정 항목을 요청합니다.
4. <strong>초안을 원문과 대조합니다.</strong> 사실과 제안을 구분하고, 담당자 확인이 필요한 내용은 해결되기 전까지 미확정으로 둡니다.

<Note>커넥터를 연결해도 모든 외부 자료가 자동으로 색인되지는 않습니다. [자료 검색 범위](/ko/knowledge/rag)와 각 [커넥터의 읽기 범위](/ko/guides/connectors)를 확인하세요. 생성한 답을 다시 사용할 때도 원래 근거와 기준일을 확인합니다.</Note>
