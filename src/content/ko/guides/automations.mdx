GitHub에 코드를 반영할 때 연결된 문서와 설계도를 함께 최신화할 수 있습니다. 자동 갱신은 각 문서·캔버스의 저장소 연결을 기준으로 동작합니다.

## 자동 갱신 시작하기

1. [GitHub를 연결](/ko/guides/github)하고 문서 또는 캔버스를 만듭니다.
2. 콘텐츠의 **연결** → **연결 관리** → **이벤트 연결**에서 저장소를 체크합니다.
3. 표시된 기본 브랜치에 다음 push가 발생하면 관련 변경을 분석합니다.

문서와 캔버스는 각각 연결합니다. 같은 저장소를 여러 콘텐츠에 연결하거나 하나의 콘텐츠에 여러 저장소를 연결할 수 있습니다.

## 실행에서 하는 일

에이전트는 변경 차이와 현재 브랜치, 기존 콘텐츠를 확인해 필요한 부분을 직접 수정합니다. 관련 내용이 이미 최신이면 기존 문서를 유지할 수 있습니다. 캔버스는 기존 설계도에서 관련 요소를 갱신합니다.

연속 push가 발생하면 최신 실행이 이전 실행을 대체할 수 있습니다. 현재 코드 상태에 맞는 결과가 남았는지 확인하세요.

## 실행 결과 확인하기

**연결** → **실행 기록**으로 인박스를 열어 실행 상태와 분석 범위를 확인합니다. 실제로 저장된 문서와 캔버스도 열어 검토하세요. 문서 변경 이력에서 AI 변경을 확인하고 되돌릴 수 있습니다.

## 일시 중단과 연결 해제

에이전트 편집 잠금을 켜면 자동 갱신이 중단되며, 사람은 계속 편집할 수 있습니다. 향후 push를 더 이상 반영하지 않으려면 **이벤트 연결**에서 저장소 체크를 해제합니다.

갱신되지 않으면 GitHub 연결 상태, 소유자의 GitHub 사용 설정, 저장소 접근 권한과 콘텐츠 쓰기 권한을 확인하세요. 상세 절차는 [연결 관리](/ko/guides/automation-settings)를 참고하세요.
