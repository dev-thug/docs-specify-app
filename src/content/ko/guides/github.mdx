GitHub를 연결하면 Specify가 저장소의 코드와 개발 이력을 읽고, 기능 문서와 아키텍처 설계도를 만들 수 있습니다. 저장소 접근 권한과 문서의 자동 갱신 연결은 별도로 설정합니다.

## GitHub 연결하기

1. **도구** → **커넥터**에서 GitHub를 엽니다.
2. **연동**을 누르고 GitHub에서 계정과 접근을 허용할 저장소를 선택합니다.
3. Specify로 돌아와 연결 상태와 **에이전트 접근**을 확인합니다.

GitHub 앱에 접근을 허용한 저장소를 사용할 수 있습니다. 필요한 저장소가 있다면 앱 설치 설정의 접근 범위에 추가하세요.

## 조직 저장소와 접근 권한

조직 정책에 따라 관리자의 승인이 필요할 수 있습니다. 승인 후 Specify로 돌아와 다시 연결하세요. 저장소가 누락됐다면 GitHub의 앱 설치 설정에서 접근 범위를 수정한 뒤 대화로 돌아와 다시 확인하도록 요청합니다.

인증이 만료됐다면 **재연결**을 사용합니다. GitHub 앱 설치가 일시 중지됐거나 저장소 권한이 제거됐다면 해당 설정도 복구해야 합니다.

## 코드로 문서 만들기

채팅에서 저장소를 지정하고 어떤 문서나 설계도를 만들지 요청합니다. 기능 범위, 대상 독자, 확인할 브랜치를 함께 적으면 분석 범위가 분명해집니다. [문서와 설계도 만들기](/ko/guides/doc-projects)를 참고하세요.

## push와 자동 갱신 연결하기

문서 또는 캔버스의 **연결** → **연결 관리** → **이벤트 연결**에서 저장소를 체크합니다. 기본 브랜치에 push가 발생하면 연결된 콘텐츠를 직접 갱신합니다. 채팅에서 참조한 저장소도 이 메뉴에서 연결하면 자동 갱신을 시작할 수 있습니다.

[연결 관리](/ko/guides/automation-settings)에서 트리거와 중단 조건을 확인하세요.
