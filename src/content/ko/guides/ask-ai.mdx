IDE의 AI는 코드 자체는 잘 알지만 "왜 이렇게 만들었는지"는 모릅니다. Specify의 AI는 워크스페이스에 쌓인 문서·대화·결정·코드 기록을 근거로 답합니다.

## 잘 답할 수 있는 질문

| 질문 유형 | 예시 |
| --- | --- |
| **왜(Why)** | "결제 재시도를 큐로 분리한 이유가 뭐야?" |
| **어디(Where)** | "알림 설정 저장 로직은 어디에 있어?" |
| **어떻게(How)** | "새 API 엔드포인트를 추가할 때 어떤 순서로 작업해?" |
| **현황** | "이번 주에 인증 관련해서 바뀐 게 있어?" |

## 더 좋은 답을 얻는 방법

- **범위를 좁혀 묻습니다.** 서비스 이름, 기능 이름, 기간을 함께 적으면 근거를 찾기 쉽습니다.
- **근거를 확인합니다.** 중요한 결정에 쓰기 전에 답변의 근거가 된 문서와 코드를 직접 확인하세요.
- **답을 문서로 남깁니다.** 반복해서 나오는 질문의 답은 문서로 정리해 두면 다음 질문의 근거가 됩니다.

<Note>
  AI는 워크스페이스 권한이 허용한 문서만 근거로 사용합니다. 접근 권한이 없는 문서의 내용은 답변에 포함되지 않습니다.
</Note>

## 비개발 동료와 함께 쓰기

기술 문서가 어려운 동료도 평소 언어로 물으면 이해할 수 있는 답을 받을 수 있습니다. "이번 릴리스에서 고객에게 보이는 변화가 뭐야?"처럼 물어보면 개발팀을 붙잡지 않고 프로젝트 상황을 파악할 수 있습니다.
