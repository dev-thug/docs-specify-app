커넥터를 연결하면 외부 서비스의 정보를 AI가 참고하고, 일부 작업은 에이전트에게 맡길 수 있습니다. 커넥터는 **설정** → **도구와 스킬** → **커넥터**에서 관리합니다. 사이드바 계정 메뉴의 **스킬 및 커넥터**로도 들어갈 수 있습니다.

## 지원하는 서비스

| 서비스 | 설명 |
| --- | --- |
| **GitHub** | 코드 협업 플랫폼 — 저장소 코드, 이슈·PR, 커밋 이력 |
| **Notion** | 문서·데이터베이스 워크스페이스 |
| **Slack** | 팀 메신저 |
| **Jira** | Atlassian 이슈 트래커 |
| **Linear** | 이슈 트래킹 도구 |
| **Google** | Gmail·캘린더·드라이브 통합 연동 |

목록 위쪽의 **전체 · 연결됨 · 이용 가능 · 조치 필요** 필터와 카테고리, **앱 검색**으로 원하는 커넥터를 찾습니다.

## 연결하기

<Steps>
  <Step title="커넥터 열기">
    연결할 서비스 카드를 누르면 상세 화면이 열립니다. **에이전트가 읽는 데이터**와 **에이전트에게 맡길 수 있는 작업**을 먼저 확인하세요.
  </Step>
  <Step title="워크스페이스에 연동">
    **워크스페이스에 연동**의 **연동** 버튼을 누르고, 서비스 화면에서 접근을 허용합니다. 연동하면 멤버와 에이전트가 함께 사용할 수 있습니다.
  </Step>
  <Step title="상태 확인">
    연결되면 카드가 **연결됨**으로 바뀝니다. 인증이 만료되면 **재연결 필요**가 표시되며, **재연결**을 눌러 다시 인증합니다.
  </Step>
</Steps>

<Screenshot name="connector-github" alt="GitHub 커넥터 상세 화면. 워크스페이스에 연동 버튼, 소개, 에이전트가 읽는 데이터, 에이전트에게 맡길 수 있는 작업 목록이 있다" />

<Note>
  커넥터 연결은 워크스페이스 관리자만 할 수 있습니다. 조직 GitHub 저장소는 GitHub 조직 관리자의 승인 후 연결됩니다.
</Note>

## Slack 고급 설정

Slack을 연결하면 **고급 설정**에서 **에이전트가 검색할 채널**과 **검색에서 제외할 채널**을 지정할 수 있습니다. 공개 채널의 메시지만 검색 대상이 됩니다.

## 커스텀 MCP 서버

목록에 없는 도구는 MCP 서버로 직접 연결할 수 있습니다.

1. **커스텀 MCP 서버 추가**를 누릅니다.
2. **서버 URL**, **네임스페이스**, **표시 이름**을 입력합니다.
3. **인증** 방식을 고르고, 필요하면 **헤더 이름**과 **시크릿**을 입력합니다.
4. 서버를 신뢰한다는 동의에 체크하고 저장합니다.

<Warning>
  커스텀 MCP 서버는 에이전트가 호출하는 외부 도구가 됩니다. 신뢰할 수 있는 서버만 추가하고, 시크릿은 권한이 최소한인 값을 쓰세요.
</Warning>

## 연결 해제

커넥터 상세 화면에서 연동을 제거할 수 있습니다. 제거하면 에이전트는 해당 서비스의 정보를 더 이상 읽지 않습니다.
