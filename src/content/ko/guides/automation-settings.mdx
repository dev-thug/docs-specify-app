자동 갱신은 문서·캔버스마다 연결한 저장소를 기준으로 실행됩니다. 콘텐츠의 **연결**에서 현재 연결과 브랜치를 확인하고, 소유자가 연결을 관리합니다.

## 저장소 연결과 해제

1. 문서 또는 캔버스를 엽니다.
2. **연결** → **연결 관리** → **이벤트 연결**을 엽니다. 콘텐츠 메뉴의 **이벤트 연결**에서도 설정할 수 있습니다.
3. 연결할 저장소를 체크합니다. 체크를 해제하면 해당 저장소의 향후 push 갱신을 중단합니다.

목록에는 저장소와 브랜치가 표시됩니다. 새 연결은 저장소의 기본 브랜치를 사용합니다. 여러 저장소를 연결할 수 있으며, 문서와 캔버스는 각각 설정합니다.

## 연결 상태 읽기

**연결**에는 저장소, 연결된 브랜치, GitHub 연결 상태가 표시됩니다. 연결 상태 새로고침으로 다시 확인할 수 있습니다.

- 연결이 끊겼다면 워크스페이스의 GitHub를 다시 연결합니다.
- 앱 설치가 일시 중지됐다면 GitHub에서 복구합니다.
- 상태를 확인할 수 없다면 새로고침한 뒤 접근 권한을 확인합니다.

GitHub 연결이 활성 상태여도 소유자의 GitHub 사용 설정, 저장소 접근 권한, 콘텐츠 쓰기 권한이 있어야 실행됩니다.

## 에이전트 편집 잠금

에이전트 편집 잠금으로 사람이 수정하는 동안 자동 갱신을 일시 중단할 수 있습니다. 다시 허용할 때 잠금을 해제합니다. 잠금을 해제한 뒤 실행 여부는 인박스에서 확인하세요.

## 갱신 범위와 결과

에이전트는 연결된 기존 콘텐츠를 읽고 관련된 사실만 수정합니다. 문서의 언어와 목적, 관련 없는 내용과 보호된 내용은 유지하도록 동작합니다. 캔버스도 기존 객체와 배치를 바탕으로 갱신합니다.

**실행 기록**에서 실행 결과를 열고 [자동 갱신 결과 확인](/ko/guides/review-proposals)을 진행하세요.
