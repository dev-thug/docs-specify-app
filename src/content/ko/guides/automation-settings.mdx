문서 프로젝트의 **자동화 상세 설정**에서 연결된 저장소, 문서 갱신 방식, 작성 기본값을 관리합니다. 프로젝트 설정은 **프로젝트**, **저장소**, **자동화**, **문서 작성** 항목으로 나뉩니다.

## 저장소와 push 트리거

**저장소** 항목에서 문서의 근거로 사용할 저장소와 브랜치를 연결합니다. 소스마다 **push 시 실행**을 켜면 해당 브랜치에 코드를 올릴 때도 문서 수정안을 준비합니다.

<Tip>
  기본 브랜치(예: `main`)에만 push 트리거를 켜 두면, 작업 중인 브랜치의 변경이 수정안으로 섞이지 않습니다.
</Tip>

## 작성 스킬

**작성 스킬**은 에이전트가 문서를 생성할 때 따르는 작성 규율입니다. 문서 종류에 맞는 스킬을 고르고, 필요하면 보조 스킬을 추가합니다. 보조 스킬은 최대 5개까지 선택할 수 있습니다.

## 기본 출력 폴더

생성된 문서가 저장될 폴더를 선택합니다. 선택하지 않으면 현재 프로젝트 폴더에 저장됩니다.

## 프로젝트 스타일 가이드

이 프로젝트의 문서에 적용할 마크다운 규칙을 적습니다. 워크스페이스 스타일 가이드보다 구체적이므로, 충돌하면 프로젝트 스타일 가이드가 우선합니다. 비워 두면 워크스페이스 가이드만 적용됩니다.

```md title="프로젝트 스타일 가이드 예시"
## 문체
- 표 대신 문장으로 씁니다
- 각 섹션에 담당 팀을 밝힙니다

## 용어
- "사용자" 대신 "고객"이라고 씁니다
- API 이름은 코드 표기(`like_this`)로 씁니다
```

## 반영 정책

수정안을 자동으로 반영할지는 프로젝트 설정과 워크스페이스에 적용된 정책을 따릅니다. 새 프로젝트는 자동 반영 없이 시작하며, 자동 반영이 허용된 경우 저위험 변경이 자동 승인될 수 있습니다. 검토 흐름은 [수정안 검토와 반영](/ko/guides/review-proposals)을 참고하세요.
