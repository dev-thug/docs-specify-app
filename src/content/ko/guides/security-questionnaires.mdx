현재 정책과 실제 운영 근거로 보안 질문의 답변 초안을 준비하세요. 확인이 필요한 항목을 담당자별 질문으로 정리하면 검토와 후속 조치를 이어가기 쉽습니다.

## 준비할 자료

고객 질문, 현행 보안·개인정보 정책, 운영 증적, 이전 답변을 준비합니다. 기준일, 적용 서비스와 폐기 여부를 표시합니다. 민감한 고객·계정 정보와 시크릿은 제외합니다.

## 질문별 답변과 근거 정리하기

채팅으로 질문별 짧은 답변, 근거 문서, 적용 범위, 확인 상태를 표로 정리하도록 요청합니다. 과거 답변은 현행 정책과 대조해 갱신하세요. 추가 근거가 필요하면 원문 접근과 검색 범위를 확인하고, 인증 보유 여부는 공식 증서나 담당자 확인으로 확정합니다.

## 검토와 후속 개선

보안 담당자가 실제 운영과 답변이 일치하는지 확인한 뒤 고객 양식에 옮기고 제출합니다. 보완할 기능과 절차는 현재 상태를 명시하고 개선 문서로 정리합니다. 코드 변경이 필요한 항목은 코딩 에이전트가 MCP로 읽어 구현 범위를 검토하게 할 수 있습니다.

## 채팅 요청 예시

```text
고객 보안 질문과 현행 정책, 과거 답변을 읽어 줘.
질문 / 답변 초안 / 근거 문서 / 적용 범위 / 확인 상태 표를 작성해 줘.
자료가 충돌하거나 운영 증적이 없는 항목은 담당자 확인 필요로 남겨 줘.
확인되지 않은 인증이나 통제를 보유·완료했다고 쓰지 말아 줘.
```

<Note>이 흐름으로 검토용 답변을 준비하고, 담당자 확인을 마친 답변을 고객 양식에 옮겨 제출하세요. 인증 문서 준비와 전문 검토가 필요하면 [Specify 인증 지원](https://certify.specify.app)에서 제품에 맞는 준비 경로와 지원 범위를 확인하세요.</Note>
