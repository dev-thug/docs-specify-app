**스킬**은 에이전트가 특정 작업을 할 때 따르는 절차와 사용 조건입니다. **플러그인**은 여러 스킬(과 에이전트·MCP 서버·이벤트 훅)을 묶은 패키지로, 공식 마켓플레이스에서 한 번에 설치할 수 있습니다.

## 플러그인 설치하기

**설정** → **AI 에이전트** → **플러그인**에서 공식 마켓플레이스를 둘러봅니다.

<Screenshot name="settings-plugins" alt="플러그인 화면. 카탈로그와 설치됨 탭, 카테고리 필터, doc-quality, specify-docs, medical-device-docs 등 추천 플러그인 목록이 있다" />

1. **카탈로그** 탭에서 카테고리(생산성, 커뮤니케이션, 개발, 디자인, 마케팅, 재무, 법무)로 거르거나 검색합니다.
2. 플러그인을 눌러 **포함된 구성 요소**와 **요청 권한**을 확인합니다.
3. **+** 또는 **설치**를 누릅니다. 설치된 플러그인은 **설치됨** 탭에서 확인하고 **제거**할 수 있습니다.

설치된 스킬은 이 워크스페이스의 에이전트가 사용합니다.

### 주요 공식 플러그인

| 플러그인 | 설명 |
| --- | --- |
| **specify-docs** | Specify 공식 문서 스킬 |
| **doc-quality** | 문서 품질 검토 스킬 묶음 |
| **eng-quality** | 장애 회고·기술 문서 품질 등 엔지니어링 품질 스킬 |
| **medical-device-docs** | 의료기기 소프트웨어 문서 팩(IEC 62304·ISO 14971) — 코드와 표준 근거 기반 |
| **productivity-meetings** | 회의록 정리·액션아이템 추출 등 회의 생산성 스킬 |
| **marketing-content** | 콘텐츠 브리프·캠페인 카피 등 마케팅 콘텐츠 스킬 |

**medical-device-docs**는 표준 조항을 검색해 인용하며 문서를 씁니다. [표준 문서 라이브러리](/ko/knowledge/standards)를 참고하세요.

### GitHub에서 가져오기

플러그인 화면의 **추가** → **GitHub 리포 임포트**로 GitHub 저장소에 있는 플러그인을 가져올 수 있습니다. **GitHub 리포 URL**과 선택적으로 **브랜치·태그·커밋**을 입력합니다.

## 스킬 관리하기

**설정** → **도구와 스킬** → **스킬**에서 워크스페이스의 스킬을 봅니다.

<Screenshot name="tools-skills" alt="스킬 화면. 전체, 내 스킬, 에이전트 학습, 플러그인 탭과 사용 중인 스킬 카드 목록이 있다" />

- **전체 · 내 스킬 · 에이전트 학습 · 플러그인** 탭으로 출처별로 거릅니다.
- **추가**로 새 스킬을 만듭니다. 이름, 설명, 버전, 태그와 함께 **절차**(본문)를 마크다운으로 씁니다.
- 자주 쓰는 스킬은 고정해 목록 맨 앞에 둡니다.
- 스킬을 **SKILL.md 내보내기**로 파일로 내려받을 수 있습니다.

<Tip>
  좋은 스킬은 "언제 쓰는지"와 "어떤 순서로 하는지"가 분명합니다. 설명에 사용 조건을, 절차에 단계와 완료 기준을 적으세요.
</Tip>

## 에이전트 학습

에이전트는 대화에서 배운 내용을 **메모리**와 **스킬**로 자동 저장합니다. **설정** → **AI 에이전트** → **에이전트 학습**에서 **활동**, **메모리**, **스킬**, **큐레이터 이력**을 확인하고, 필요 없는 기억은 삭제하거나 스킬 변경을 이전 버전으로 되돌릴 수 있습니다.

## 문서 프로젝트에서 스킬 쓰기

[문서 프로젝트](/ko/guides/doc-projects)를 만들 때 고르는 **문서 스킬**도 같은 스킬입니다. 설치된 문서 스킬이 없다면 마켓플레이스에서 찾거나 새로 만들 수 있고, 보조 스킬은 최대 5개까지 함께 쓸 수 있습니다.
