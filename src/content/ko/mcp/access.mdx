MCP 접근은 토큰의 권한 범위, 워크스페이스 역할과 접근 정책을 함께 확인합니다. 필요한 범위만 허용하세요.

## 읽기와 쓰기

기본 범위인 `mcp:read`는 문서 탐색, 검색, 본문·변경 기록·캔버스 읽기에 사용합니다. `mcp:write`는 문서·캔버스 생성과 수정, 이전 버전 복원, 폴더와 휴지통 작업 등 워크스페이스를 변경하는 도구에 필요합니다. 정확한 도구 목록은 [제공 도구](/ko/mcp/tools)를 참고하세요.

쓰기 작업에는 쓰기 범위, 해당 작업을 허용하는 워크스페이스 역할과 쓰기 가능 상태가 필요합니다. 연결 화면의 **문서 생성·수정 허용**을 선택하면 쓰기 범위가 포함됩니다. 자료를 읽는 용도라면 기본 읽기 전용으로 연결하세요.

## 내 접근 권한 관리

**도구와 스킬**의 **에디터 연결**에서 발급한 접근 권한과 마지막 사용을 확인하고 필요 없는 권한을 종료합니다. 목록은 발급 내역과 사용 기록을 보여 줍니다. 실제 연결은 에디터에서 도구를 호출해 확인하세요.

토큰은 공유하지 마세요. 노출이 의심되면 기존 접근을 종료하고 새로 연결하세요. 종료된 토큰은 이후 요청에 사용할 수 없습니다.

## 워크스페이스 정책

관리자와 소유자는 외부 에디터 접근의 허용 여부, 도구별 정책, 워크스페이스 토큰과 사용 현황을 관리합니다. 일반 멤버는 자신의 연결을 관리하며 전체 정책은 관리자에게 문의합니다.

MCP 노출에서 제외된 문서·폴더와 하위 자료는 검색과 읽기, 편집에서 제외됩니다. 권한 오류가 나면 토큰 범위, 멤버십, 역할, 관리자 정책을 확인하세요.
