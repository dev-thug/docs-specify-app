Specify MCP 서버는 다섯 개의 도구를 제공합니다. 읽기 도구는 `mcp:read`, 쓰기 도구는 `mcp:write` 권한 범위가 필요합니다. 정확한 입력 스키마는 클라이언트가 `tools/list` 로 받는 JSON Schema가 기준입니다.

## 도구 목록

| 도구 | 권한 범위 | 하는 일 |
| --- | --- | --- |
| `search` | `mcp:read` | 워크스페이스 문서를 의미·제목 기준으로 검색하고, 활성화된 외부 커넥터 결과를 출처별로 묶어 반환합니다. |
| `read_document` | `mcp:read` | 텍스트·PDF 문서의 전체 본문 또는 일부 구간을 읽습니다. |
| `browse` | `mcp:read` | 문서 트리, 최근 문서, 제목 검색으로 워크스페이스를 탐색합니다. |
| `create_document` | `mcp:write` | 마크다운 본문으로 새 문서를 만듭니다. |
| `update_document` | `mcp:write` | 문서의 특정 텍스트를 정확히 찾아 바꾸거나 본문 끝에 추가합니다. |

## search

작업에 필요한 문서를 찾을 때 씁니다.

| 입력 | 설명 |
| --- | --- |
| `query` | 검색어 |
| `topK` | 선택. 반환할 결과 수(1–25) |

## read_document

검색이나 탐색으로 찾은 문서를 읽습니다. 긴 문서는 구간 단위로 나눠 읽을 수 있습니다.

| 입력 | 설명 |
| --- | --- |
| `nodeId` | 읽을 문서의 ID |
| `around`, `offset`, `limit`, `page` | 선택. 읽을 구간을 지정합니다. |

## browse

| 입력 | 설명 |
| --- | --- |
| `mode` | `tree`(문서 트리), `recent`(최근 문서), `search`(제목 검색) 중 하나 |
| `query` | 선택. `search` 모드의 검색어 |
| `limit` | 선택. 반환할 항목 수 |

## create_document

| 입력 | 설명 |
| --- | --- |
| `title` | 문서 제목 |
| `content` | 마크다운 본문 |
| `parentNodeId` | 선택. 문서를 만들 상위 폴더 |

## update_document

| 입력 | 설명 |
| --- | --- |
| `nodeId` | 고칠 문서의 ID |
| `search` | 선택. 바꿀 텍스트(정확히 일치해야 합니다) |
| `replace` | 바꿀 내용. `search` 가 없으면 본문 끝에 추가합니다. |

업로드한 파일 문서는 수정할 수 없습니다.

## 권한과 제한

- 모든 도구 호출은 매번 토큰, 워크스페이스 멤버십, 권한 범위, 관리자 접근 정책, 호출 한도를 확인합니다. 멤버가 탈퇴하거나 토큰이 폐기되면 기존 토큰으로 더 이상 데이터에 접근할 수 없습니다.
- 쓰기 도구는 편집자 이상의 워크스페이스 역할이 필요하며, 워크스페이스 쓰기가 잠겨 있으면 실행되지 않습니다.
- MCP 노출에서 제외된 문서·폴더와 그 하위 경로는 검색·읽기·수정 결과에 나타나지 않습니다.
- 입력이나 권한 문제로 도구 실행이 실패하면, 에이전트가 읽고 수정할 수 있는 설명과 함께 오류 결과를 반환합니다.
