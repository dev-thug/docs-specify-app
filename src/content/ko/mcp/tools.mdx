Specify MCP는 Specify 에이전트와 같은 작업공간·지식 검색 도구를 외부 에이전트에 제공합니다. 실제 사용 가능한 도구와 입력값은 클라이언트의 `tools/list`가 반환한 스키마를 따릅니다.

## 검색과 읽기

| 도구 | 하는 일 |
| --- | --- |
| `list_files` | 문서·업로드 파일의 경로와 현재 버전을 확인합니다. |
| `search_files` | 문서 본문에서 문자열을 찾습니다. |
| `read_file` | 파일 본문을 읽습니다. `startLine`, `endLine`으로 구간을 지정할 수 있습니다. |
| `knowledge_search` | 의미가 관련된 지식 조각을 찾습니다. |
| `knowledge_grep` | 색인된 자료에서 정확한 문자열을 찾습니다. |
| `knowledge_status` | 지식 자료 처리 상태를 확인합니다. |
| `search_connectors` | 연결된 외부 서비스에서 자료를 검색합니다. |

지식·커넥터 도구의 제공 여부는 연결된 서비스와 워크스페이스 상태에 따라 달라집니다.

## 문서와 캔버스

| 도구 | 하는 일 |
| --- | --- |
| `create_document`, `write_document` | 문서를 만들거나 본문을 저장합니다. |
| `edit_document` | 기존 문서에서 지정한 텍스트를 수정합니다. |
| `list_document_history`, `read_document_revision` | 문서 변경 기록과 이전 버전을 읽습니다. |
| `revert_document` | 문서를 이전 버전으로 되돌립니다. |
| `create_canvas`, `read_canvas`, `edit_canvas` | 캔버스를 만들고 읽고 수정합니다. |

수정 전 `read_file` 또는 `read_canvas`로 최신 내용을 읽으세요. 쓰기 시 스키마가 요구하는 `baseRevision`과 위치 버전을 전달합니다. 충돌하면 다시 읽고 수정합니다. `edit_document`의 `oldText`는 정확히 한 번 일치해야 합니다.

## 폴더와 휴지통

`create_folder`, `move_entry`, `trash_entry`, `list_trash`, `restore_entry`로 폴더와 항목을 관리합니다. 삭제에 해당하는 도구는 클라이언트에 파괴적 작업으로 표시됩니다.

## 권한과 제한

읽기는 `mcp:read`, 문서·캔버스·구조를 변경하는 작업은 `mcp:write`가 필요합니다. 쓰기에는 워크스페이스 역할과 현재 접근 정책도 적용됩니다. MCP에서 제외한 문서·폴더와 그 하위 항목은 외부 접근 대상이 아닙니다.

MCP는 워크스페이스 자료를 찾아 읽고 허용된 범위에서 편집하는 연결입니다. 코드 구현을 이어갈 때에는 외부 코딩 에이전트에 문서 읽기와 구현을 직접 요청하세요. [토큰과 접근 정책](/ko/mcp/access)을 참고하세요.
