Specify MCP는 Claude Code·Codex·Cursor 같은 외부 에이전트가 팀의 문서와 자료를 검색하고 읽게 하는 연결입니다. 같은 워크스페이스 맥락을 Specify 안팎에서 사용할 수 있습니다.

## 하는 일

에이전트는 자료를 검색하고 원문을 읽어 도메인 용어, 요구사항과 결정을 확인합니다. 쓰기 권한과 적절한 역할이 있으면 문서와 캔버스를 수정할 수도 있습니다. 코드 구현은 연결한 코딩 에이전트에게 직접 요청하고 그 에이전트에서 진행 상황과 결과를 확인하세요.

## 서버와 인증

| 항목 | 내용 |
| --- | --- |
| 서버 주소 | `https://mcp.specify.app` |
| 전송 | Streamable HTTP |
| 인증 | 워크스페이스 토큰(Bearer) 또는 OAuth |
| 권한 | `mcp:read` 기본, `mcp:write` 선택 |

## 연결과 활용

**도구와 스킬** → **에디터 연결**에서 클라이언트를 선택하고 생성된 명령이나 설정을 적용합니다. 기본은 읽기 전용이며, 쓰기가 필요할 때만 추가 권한을 허용합니다.

연결 후 “이 기능의 요구사항과 최근 결정을 찾아 원문을 읽어 줘”처럼 요청하세요. 구현 전 원문을 읽고, 작업 중 문서가 바뀌었다면 다시 읽어 현재 요구사항을 확인합니다.

[클라이언트별 연결 방법](/ko/mcp/connect), [제공 도구](/ko/mcp/tools), [접근 정책](/ko/mcp/access)을 참고하세요.
