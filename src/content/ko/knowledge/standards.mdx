표준 문서 라이브러리에서 개발문서의 근거가 될 표준 조항과 판을 찾을 수 있습니다. 검색 결과와 인용을 정식 표준 원문 및 제품별 근거와 함께 검토하세요.

## 검색하는 표준

아래 표에서 필요한 표준과 판을 확인하고 검색 요청에 함께 적어 주세요.

| 표준 | 판·연도 |
| --- | --- |
| IEC 62304 | ed1.1 |
| IEC 62366-1 | ed1.1 |
| IEC 82304-1 | ed1.0 |
| ISO 13485 | 2016 |
| ISO 14971 | 2019 |
| ANSI/AAMI SW91 | 2018 |
| AAMI TIR57 | 2016 |
| AAMI TIR97 | 2019 |
| AAMI CR510 | 2021 |
| ISO/IEC 29147 | 2018 |
| ISO/IEC 30111 | 2019 |

IEC 62304는 현재 검색 대상인 ed1.1을 기준으로 요청하세요. 실제 검색 결과의 표준명과 판을 확인하면 작업에 맞는 자료를 선택할 수 있습니다.

## 검색과 인용

지식 검색으로 워크스페이스 자료와 표준 조항을 함께 찾을 수 있습니다. 자료의 처리 상태와 검색 범위를 확인하고, 필요한 제품 자료를 더하면 검토할 근거를 넓힐 수 있습니다.

인용에는 표준명, 판, 조항 번호를 남기고 해당 조항이 실제 주장을 뒷받침하는지 확인하세요. 에이전트에는 검색으로 확인한 조항을 근거로 작성하고 추가 확인할 요구사항을 구분하도록 요청합니다.

## 문서 검토

- 규범 조항과 참고·권고 내용을 구분합니다.
- 제품의 확정 정보와 담당자가 결정할 항목을 나눕니다.
- 추가 근거가 필요한 부분은 `[GAP]` 같은 표시로 모아 검토합니다.
- 인용한 표준과 판, 조항을 문서 끝에 정리하면 검토하기 쉽습니다.

표준 원문은 해당 자료의 라이선스 범위에서 이용하세요. 보유한 정식 표준으로 인용의 판·조항과 내용을 대조하면 문서의 정확성과 이용 범위를 함께 확인할 수 있습니다.

## 의료기기 문서 작성

요구사항, 아키텍처, 위험 관리와 SOUP 문서를 작성할 때 코드, 제품 정보, 표준 근거를 함께 지정하세요. 스킬은 [도구와 스킬](/ko/guides/plugins-skills)에서 관리하며, 결과는 문서나 캔버스에 저장할 수 있습니다.

생성한 초안은 담당자와 전문가의 검토를 거쳐 제출용 문서로 완성합니다. 안전 등급과 인증 적합성은 해당 평가 절차에서 제품 근거와 대조해 확정합니다. [의료기기 문서와 인증 준비](/ko/guides/medical-device-docs)를 참고하세요.
