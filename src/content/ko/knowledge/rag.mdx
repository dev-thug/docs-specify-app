Specify는 워크스페이스 문서와 업로드한 자료를 검색해 답변과 문서 작성의 근거로 사용합니다. 검색 결과를 이용해 답을 만드는 방식을 RAG(검색 증강 생성)라고 합니다.

## 검색 대상

| 자료 | 검색 방식 |
| --- | --- |
| 워크스페이스 문서 | 저장된 문서의 내용과 제목을 검색합니다. |
| 업로드한 파일 | 추출하고 색인한 내용을 검색합니다. 파일 처리 상태에 따라 검색 가능 시점이 달라집니다. |
| 표준 문서 라이브러리 | 게시된 표준 조항을 검색합니다. [표준 문서 라이브러리](/ko/knowledge/standards)를 참고하세요. |
| 외부 서비스 | GitHub·Notion·Slack 등 연결된 서비스는 워크스페이스 색인에 복제하지 않고 커넥터를 통해 검색합니다. |

## 의미 검색과 문자열 검색

의미가 비슷한 내용을 찾는 검색과 정확한 용어·문자열을 찾는 검색을 함께 사용할 수 있습니다. 전체 문서 목록은 문서 탐색으로 확인하고, 본문은 원문을 열어 확인하세요.

[MCP](/ko/mcp/tools)에서는 `knowledge_search`, `knowledge_grep`, `search_files`, `list_files`, `read_file`을 사용할 수 있습니다. 외부 서비스 검색은 `search_connectors`로 구분됩니다.

## 색인과 최신성

문서와 업로드 자료는 색인 처리가 완료되면 검색에 반영됩니다. 저장이나 업로드 직후에 자료를 찾으려면 파일 목록과 원문을 먼저 확인하세요. 검색 결과에 나타나지 않으면 처리 상태를 확인하고 검색어를 바꿔 다시 검색합니다.

## 권한과 근거 확인

검색은 현재 워크스페이스와 접근 권한의 범위에서 동작합니다. MCP 노출에서 제외한 항목은 외부 에이전트의 접근에서도 제외됩니다.

출처 링크를 열어 내용이 최신인지, 인용이 주장을 실제로 뒷받침하는지 확인하세요. 중요한 결정에 필요한 자료를 정하고 원문까지 읽어 검토 범위를 확인합니다.
