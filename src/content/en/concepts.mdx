## The overall workflow

Connect repository sources and material in a workspace, then use chat to create documents and canvases. A person reviews the result and records improvements; a coding agent reads them through MCP and updates the code. Repository-linked documents and canvases can update automatically after code changes.

## Workspaces

A workspace brings together documents, canvases, conversations, and connections. Personal and team workspaces are separate; the selected workspace and your member permissions determine what you can access.

## Documents and canvases

Documents hold written requirements, feature explanations, APIs, and improvements. Canvases let you inspect components and relationships visually. A Mermaid diagram inside a document is different from a separate canvas; request the format that fits the task.

## Explorer and folders

Open documents and canvases from the explorer and organize them in folders. Deleted content can be restored from Trash; permanently deleted content cannot be recovered.

## Chat and Inbox

Chat is a conversation for questions, analysis, and writing with AI. Inbox shows work progress and items needing attention. Archived items are available in the settings archive.

## Repository links and automatic updates

The GitHub connector lets the agent read permitted repositories. Linking a repository to a document or canvas enables direct updates based on source pushes. Configure a repository link for each document and canvas you want to update automatically.

## Edit history and human review

When a task completes, verify accuracy by comparing the saved content, source, and edit history. Agent edit locking can restrict automatic edits; check the effect on later changes before reverting.

## Knowledge search and skills

Knowledge search finds documents and files to ground an answer. Skills describe the procedures an agent should follow. For standards material, check availability, editions, and cited evidence.

## MCP and product starting points

MCP lets external agents search and read permitted workspace material, or edit documents through available writing tools.
