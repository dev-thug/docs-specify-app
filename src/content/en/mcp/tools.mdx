Specify MCP exposes the same workspace and knowledge tools used by the Specify agent to external agents. The schema returned by the client's `tools/list` defines available tools and inputs.

## Search and read

| Tool | Purpose |
| --- | --- |
| `list_files` | Lists document and uploaded-file paths and current versions. |
| `search_files` | Finds strings in document content. |
| `read_file` | Reads file content, optionally using `startLine` and `endLine`. |
| `knowledge_search` | Finds semantically related knowledge fragments. |
| `knowledge_grep` | Finds exact strings in indexed material. |
| `knowledge_status` | Checks knowledge processing status. |
| `search_connectors` | Searches connected external services. |

Knowledge and connector tool availability depends on the connected services and workspace state.

## Documents and canvases

| Tool | Purpose |
| --- | --- |
| `create_document`, `write_document` | Creates documents or saves their content. |
| `edit_document` | Edits specified text in an existing document. |
| `list_document_history`, `read_document_revision` | Reads document history and earlier revisions. |
| `revert_document` | Restores an earlier document revision. |
| `create_canvas`, `read_canvas`, `edit_canvas` | Creates, reads, and edits canvases. |

Read the latest content with `read_file` or `read_canvas` before editing. Supply the `baseRevision` and location version required by the write schema. On a conflict, read again before editing. Each `oldText` in `edit_document` must match exactly once.

## Folders and trash

Use `create_folder`, `move_entry`, `trash_entry`, `list_trash`, and `restore_entry` to manage folders and entries. Tools that remove entries are marked as destructive to the client.

## Permissions and limits

Reading requires `mcp:read`; changing documents, canvases, or structure requires `mcp:write`. Workspace roles and current access policies also apply to writes. Documents and folders excluded from MCP, including their descendants, are outside external access.

MCP provides workspace search, reading, and permitted editing. To continue implementation, ask your external coding agent directly to read the document and implement the changes. See [Tokens and access policies](/en/mcp/access).
