Specify MCP lets external agents such as Claude Code, Codex, and Cursor search and read your team's documents and material. Use the same workspace context inside and outside Specify.

## What it does

Agents search sources and read the originals to verify domain terms, requirements, and decisions. With write access and an appropriate role, they can also edit documents and canvases. Request implementation directly from your connected coding agent and check progress and results there.

## Server and authentication

| Item | Value |
| --- | --- |
| Server URL | `https://mcp.specify.app` |
| Transport | Streamable HTTP |
| Authentication | Workspace token (Bearer) or OAuth |
| Scopes | `mcp:read` by default; `mcp:write` optional |

## Connect and use

Open **Tools & skills** → **Connect editor**, select a client, and apply the generated command or configuration. Access is read-only by default; grant extra permissions only when writing is needed.

After connecting, ask the agent to find the feature's requirements and recent decisions and read the source documents. Read the originals before implementation, and read them again if they change during the work.

See [Client connections](/en/mcp/connect), [Available tools](/en/mcp/tools), and [Access policies](/en/mcp/access).
