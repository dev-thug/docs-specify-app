Coding agents are capable, but they don't know your team. Specify runs as an MCP server so agents such as Claude Code, Codex, and Cursor can explore your team's docs, decisions, and code context directly.

## What is MCP

MCP (Model Context Protocol) is an open standard for connecting AI agents to external tools and data. Because Specify provides an MCP server, any client that supports MCP can search and read your team's docs within the scope your workspace permissions allow.

## What you can do

## Server details

| Item | Value |
| --- | --- |
| Server URL | `https://mcp.specify.app` |
| Transport | Streamable HTTP (JSON responses, no SSE sessions) |
| Authentication | Workspace MCP token (Bearer) or OAuth |
| Scopes | `mcp:read` (default), `mcp:write` (optional) |
| Server name | `specify` in every client |

<Note>
  The simplest way to get connection commands and tokens is from your workspace. When you choose a connection, access permission for that workspace is issued and the commands or config for each client are prepared for you.
</Note>

## Connection at a glance

<Steps>
  <Step title="Open Connect editor in your workspace">
    Open the account menu at the bottom of the sidebar and select **Skills & connectors** to open the **Tools & skills** window. On the **Connect editor** tab, choose the client you use.

    <Screenshot name="tools-editor-connect" alt="The Connect editor tab in the Tools & skills window with client connection cards" />
  </Step>
  <Step title="Choose a scope">
    The default is read-only. If the agent needs to create or edit docs, check **Allow document creation and editing**.
  </Step>
  <Step title="Apply the command or config">
    Depending on the client, run a terminal command, paste a config, or open your editor with a deep link. For client-specific steps, see [Connect editors and agents](/en/mcp/connect).
  </Step>
  <Step title="Ask on top of your context">
    Ask about decisions, docs, or code, and the agent answers from your team's actual context instead of generic guesses.
  </Step>
</Steps>
