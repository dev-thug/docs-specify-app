MCP access checks token scopes, workspace roles, and access policies together. Grant only the access you need.

## Reading and writing

The default `mcp:read` scope covers browsing, search, and reading documents, history, and canvases. `mcp:write` is required for tools that change the workspace, including document and canvas creation and editing, revision restoration, folders, and trash operations. See [Available tools](/en/mcp/tools) for the tool list.

Writing requires write scope, a workspace role that permits the action, and a workspace that allows writes. Select **Allow document creation and editing** to include write scope. For reading material, connect with the default read-only access.

## Manage your access

Open **Tools & skills** → **Connect editor** to review issued access permissions and last use, and end access you no longer need. The list shows issued access and usage history. Verify the live connection by calling a tool from your editor.

Do not share tokens. If you suspect exposure, end the old access and connect again. Revoked tokens cannot be used for subsequent requests.

## Workspace policies

Admins and owners manage external editor access, tool policies, workspace tokens, and usage. Other members manage their own connections and should contact an administrator about workspace policies.

Documents and folders excluded from MCP, including their descendants, are excluded from search, reading, and editing. For permission errors, check token scopes, membership, role, and administrator policies.
