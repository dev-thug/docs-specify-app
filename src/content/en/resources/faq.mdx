## Getting started

### What material should I start with?

Write documents or upload files to your workspace, then name the relevant material in chat. Connect external services such as GitHub, Notion, and Slack to search them when needed.

### Do teammates need to set anything up?

Teammates accept invitations using their own accounts. Each person needs their own MCP access authorization to connect an external editor.

## Document automation

### How are code changes reflected?

Link a GitHub repository and branch to a document or canvas to update the existing item after pushes to that branch. The run reads the current content and latest source, then saves necessary changes. After completion, inspect the saved content and edit history to review the update.

### What should I check after an automatic update?

Check the inbox and run result, then inspect the actual document changes. Verify that unrelated explanations remain, changed values and removed features are reflected correctly, and citations are accurate. See [Document automation](/en/guides/review-proposals).

## AI and knowledge search

### Which model should I use?

Compare the same material and request in a small task. Check facts, omissions, saved results, and usage. See [Choosing a model](/en/models/choosing).

### How can I find the material I need?

Search by document name or a distinctive term, and check the document listing and original content too. Immediately after saving or uploading, check indexing status before searching again. External service material uses connector search separately from the workspace index. See [Workspace RAG](/en/knowledge/rag).

### Is a document ready for submission if it cites standards?

Use citations to check evidence, then review clauses, editions, normative status, and product-specific material with an expert to prepare the submission. Regulatory conformity and certification are established through the applicable assessment process. See [Standards library](/en/knowledge/standards).

## MCP and pricing

### What does MCP do?

External agents such as Claude Code and Codex search and read workspace context. With write scope and an appropriate role, they can also edit documents and canvases. See [Available tools](/en/mcp/tools).
