## Adoption

### What kind of team is Specify for?

Specify fits development teams that don't have the time or people to write docs. Teams that use AI tools such as Claude Code, Cursor, and Codex every day can use documentation automation and the MCP connection together.

### Do we need to replace our existing tools?

No. Keep your existing GitHub and editor workflows, and just add a GitHub connection. You can start a pilot with a single document.

### Do teammates need to set anything up?

Teammates just accept the invitation. No extra setup is needed to read docs or ask AI.

## Documentation automation

### Will AI change our docs on its own?

New projects start without automatic updates. Document changes driven by code changes arrive first as proposed updates with their evidence and a before-and-after view, and how they're applied after that follows your project settings and the applicable policy. When automatic updates are allowed, low-risk changes may be approved automatically.

### Are docs updated automatically when code changes?

If **Trigger on push** is on for the source and the document skill uses incremental updates, proposed updates are prepared when code lands on the selected branch. Docs that use full regeneration need to be regenerated when you need them.

### Can we use documentation automation on the Free plan?

Document projects (GitHub-based document generation and automatic updates) are a feature of the Pro, Max, Team, and Enterprise plans. On the Free plan, you can use document writing, AI chat, and Workspace RAG.

### Can we connect organization repositories?

Yes. Organization repositories connect after a GitHub organization admin approves the request. After approval, select reconnect in Specify to finish.

## Security

### Are our code and docs safe?

All data runs on AWS infrastructure, isolated per workspace, and is visible only to approved members. We don't use customer data to train AI models. For details, see [Security and data](/en/resources/security).

## AI and models

### Which model should we use?

Start everyday document drafting and editing with GPT-6 Luna. Claude Haiku 5.5 can also handle targeted changes to sentences, tables, and multiple documents. Compare another model on the same request when you need faster responses or a different structure. See [Choosing a model](/en/models/choosing) for task criteria and tool call and editing performance.

### What does AI base its answers on?

It uses Workspace RAG to search your team's documents, uploaded files, and messages from connected Slack public channels as evidence, and shows links to the documents it relied on. Search runs only within workspaces you're a member of. See [Workspace RAG](/en/knowledge/rag).

### Can it write regulatory documents accurately?

In workspaces where the standards library is available, the agent searches and cites clauses from standards such as IEC 62304 and ISO 14971 as it writes. Content without evidence is marked `[GAP]`. Generated documents are drafts that need expert review before submission. See [Standards library](/en/knowledge/standards).

## MCP

### Which coding agents can we connect?

Any client that supports MCP, including Claude Code, Codex, Cursor, VS Code, and Claude Desktop. See [Connect editors and agents](/en/mcp/connect).

### Can agents edit docs too?

Yes, if you check **Allow document creation and editing** when issuing the token. The default is read-only, and admins can block creating and editing with a workspace policy.
