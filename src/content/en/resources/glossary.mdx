These are the main terms used in Specify.

## Material and work

| Term | Meaning |
| --- | --- |
| Workspace | The scope in which documents, conversations, members, and connected tools are shared. |
| Document | Text content that can be saved, edited, and reviewed through change history. |
| Canvas | Material that expresses structure or architecture through elements and connections. |
| Repository link | A connection between a document or canvas and a GitHub repository and branch for reflecting code changes. |
| Automatic update | Work triggered by a push to a linked branch that reconciles an existing document or canvas with current source. |
| Inbox | The place to check background task progress and results. |
| Thread | A conversation with the agent. |

## Knowledge and tools

| Term | Meaning |
| --- | --- |
| RAG | Retrieval-augmented generation: building answers from retrieved evidence. |
| Indexing | Processing documents and files into searchable material. |
| Standards library | A knowledge source for searching standard clauses and editions as evidence. |
| Skill | Instructions an agent follows for a specific task. |
| Connector | A connection to an external service such as GitHub, Notion, or Slack. |
| MCP | A protocol through which external AI clients use tools and material. |
| MCP token | Credentials used by an external client to access a workspace; read-only by default. |
| Revision | The version of a document or canvas that was read or edited; used to detect write conflicts. |
| Reasoning effort | A model's reasoning setting. Supported levels depend on the model and plan. |
| [GAP] | A marker for material requiring additional evidence or human confirmation. |
