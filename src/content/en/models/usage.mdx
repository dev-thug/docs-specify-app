AI usage is managed per workspace. Check the current workspace's usage when using chat and background AI tasks.

## Check usage

Open **Settings** → **Plans & Billing** → **Usage** to see the usage period and AI usage percentage. Switching workspaces changes the displayed usage. Also check the refresh and reset times shown on screen.

<Screenshot name="usage-panel" alt="Workspace AI usage and current period" caption="Check the current workspace’s period, usage percentage, and last checked time together." />

## What affects usage

The model, input and output length, reasoning effort, and tool use affect usage. Even the same request can use different amounts depending on the sources read and conversation length.

- Specify the documents and the exact scope of an edit.
- Start short tasks with a supported lower reasoning effort.
- Start a new conversation for a new topic to reduce unnecessary context.
- Keep repository links and the documents and canvases they update scoped to what you need.

## Limits and top-ups

AI tasks may be restricted when the budget is exhausted. Follow the on-screen guidance to check your plan and top-up availability. The [pricing page](https://specify.app/pricing) is the reference for prices, plan limits, and billing terms.

Check each run’s completion state and saved result. If a run stops or fails, request the remaining work. Check remaining usage and the success of each run separately.
