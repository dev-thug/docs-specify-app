## Keep documents consistent

Consistency means checking **documents against code**, **facts across related documents**, and **whether citations support claims**. Assess these separately from successful tool execution or document storage.

| Check | What a good result looks like |
| --- | --- |
| **Defaults, policies, and limits** | The overview, API reference, and operational documents describe the same current code values. |
| **Deleted features** | No descriptions, examples, or links still present them as current; relevant change guidance is included. |
| **Names and paths** | The saved title, body heading, and source links use the same current names. |
| **Requests, responses, and errors** | Descriptions and examples match behavior verified in code and tests. |
| **Citation evidence** | Paths and line ranges are valid, and the source actually supports the sentence's claim. |
| **Existing team explanations** | Manually written content and operational explanations unrelated to the code change are preserved. |

Specify **both the changed facts and the documents to check**. For example: “Compare the default limit change across the overview, API reference, and operations guide, and resolve conflicting values and unsupported explanations.” Use Luna or Haiku for clearly scoped edits first, then compare another model when source interpretation or connections across documents need improvement. Choose by **complete coverage and accurate evidence**.

## When to change models

- **If the desired section was not edited**, specify the document, edit location, what should change, and what should stay. If results remain insufficient, compare another model on the same request.
- **If a long document lacks structure**, set the outline and required items first, then write section by section. Compare Sonnet, Sol, or Opus when explanation or analysis needs improvement.
- **If code changes affect several documents**, compare values and examples across the overview, reference, and operational documents. A larger model does not guarantee complete coverage.
- **If citations matter**, compare the answer with its cited source. Check that the source supports the explanation as well as that the link opens.

## Choose reasoning effort

For short drafts and targeted edits, start with **Off** or a supported low level. Raise effort when comparing several sources or developing deeper explanations, and compare the results. Higher effort can increase time and usage. The Free plan fixes effort at **Off**.
