## When to change models

- **If the desired section was not edited**, specify the document, edit location, what should change, and what should stay. If results remain insufficient, compare another model on the same request.
- **If a long document lacks structure**, set the outline and required items first, then write section by section. Compare Sonnet, Sol, or Opus when explanation or analysis needs improvement.
- **If code changes affect several documents**, compare values and examples across the overview, reference, and operational documents. A larger model does not guarantee complete coverage.
- **If citations matter**, compare the answer with its cited source. Check that the source supports the explanation as well as that the link opens.

## Choose reasoning effort

For short drafts and targeted edits, start with **Off** or a supported low level. Raise effort when comparing several sources or developing deeper explanations, and compare the results. Higher effort can increase time and usage. The Free plan fixes effort at **Off**.
