Specify offers six models from the Anthropic Claude and OpenAI GPT families. Choose a model for each conversation in the chat message box, and set the default models for automations and document generation in workspace settings.

## Compare models

| Model | Provider | Available on | Context | Max output |
| --- | --- | --- | --- | --- |
| **Claude Opus 5.5** | Anthropic | Pro and above | 200K | 128K |
| **Claude Sonnet 5.5** | Anthropic | Pro and above | 200K | 128K |
| **Claude Haiku 5.5** | Anthropic | All plans, including Free | 200K | 64K |
| **GPT-6.1 Sol** | OpenAI | Pro and above | 1.05M | 128K |
| **GPT-5.6 Terra** | OpenAI | Pro and above | 1.05M | 128K |
| **GPT-6 Luna** | OpenAI | All plans, including Free | 1.05M | 128K |

- For current prices and limits, see the [pricing page](https://specify.app/en/pricing). For how usage is calculated, see [Usage and AI budget](/en/models/usage).
- Every model supports tool calls (searching knowledge, reading and writing documents, and more) and parallel tool calls.
- The default model for new conversations is **GPT-6 Luna**.

## Reasoning effort

You can set **reasoning effort** to one of six levels: **Off**, **Low**, **Medium**, **High**, **Extra**, or **Max**. Claude Opus 5.5 and GPT-6.1 Sol don't support Off, so they offer five levels starting at Low. Higher effort means deeper reasoning before answering, but responses are slower and use more tokens.

<Note>
  On the Free plan, reasoning effort is fixed at **Off**. When you switch models, the current reasoning effort is adjusted to the range the new model supports.
</Note>

## Where to choose a model

| Location | Applies to |
| --- | --- |
| The model button in the chat message box | The whole current conversation. It can't be changed while a response is in progress. |
| **Settings** → **Workspace general** → **Default AI Model** | Automations in this workspace |
| **Settings** → **Workspace general** → **Doc Generation Model** | Document automation (project creation and automatic updates) |

Models that aren't available on your plan show a lock in the menu, and selecting one shows a plan upgrade prompt. Specify never silently swaps the model you requested for a different one.
