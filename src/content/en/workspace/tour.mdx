Use the sidebar to find material and conversations, and the central tabs to open documents and chats. Documents and canvases work alongside conversations to organize team knowledge.

## Sidebar and search

Browse documents, chats, and the inbox from the sidebar. Use **Search** or <Kbd>⌘K</Kbd> to open the command palette and find documents or run commands.

Organize documents and folders in the explorer. Deleted material can be restored from trash. The account menu at the bottom lets you switch workspaces or open settings.

## Create something new

Start these actions from the sidebar's **New** menu.

- **New Document** — Create and edit a blank document.
- **New Chat** — Start a new AI conversation.
- **Add Resource** — Upload a file as workspace material.

To create documentation from GitHub code, name the repository and desired document in chat. Link a repository to the resulting document or canvas to use automatic updates when code changes.

## Document and chat tabs

Open several documents and conversations in tabs and move between them. In chat, select the model and reasoning effort and specify relevant sources. See [Document editing](/en/guides/editor) and [AI chat](/en/guides/ask-ai).

## Inbox and results

Check background task progress and results in the inbox. When a run finishes, open the actual document or canvas as well as its summary to inspect the changes.

When moving between personal and team work, check the current workspace first. Manage members and tool connections in [Settings](/en/workspace/settings).
