Prepare medical device software documentation by separating code-supported behavior and structure from product and safety decisions. Manage drafts in Specify and arrange specialist review where needed.

## Define the product and document scope

Prepare the product version, intended purpose, target users, software scope, and existing requirements, design, and test materials. Establish intended purpose, safety decisions, and applicable standards using product evidence and expert review. Visit [Specify certification support](https://certify.specify.app) for medical device software documentation preparation and support scope.

## Draft from source evidence

Connect the repository and ask in chat to explain implemented features and architecture. Use that evidence to draft requirements and design descriptions, recording source files, related items, and unknowns. Use dependency inventories as input to external software review. Owners assess each dependency’s purpose, risks, and verification evidence as part of the safety review.

## Address gaps and manage changes

An owner checks links among requirements, design, and test results, and identifies missing evidence. Record gaps as questions and improvement documents; a coding agent can read implementation changes over MCP. Documents and canvases linked to the repository and branch can be edited directly after pushes, so review the changes and consistency across documents.

## Example chat request

```text
Read the source for the target product version and the existing requirements, design, and test materials.
Organize code-supported behavior and structure, related files, and document references.
Leave questions for unconfirmed product information and missing evidence.
Do not describe code analysis as completed safety validation or a certification conformity decision.
```

<Note>Prepare drafts and manage changes in Specify, then have responsible owners and specialists handle regulatory and safety decisions, test execution, and final submission review. Certification and assessment outcomes are determined through the applicable assessment process. Confirm the actual documents and specialist service scope through consultation.</Note>
