Review code and requirements in the same context, then let your coding agent read the agreed improvement document over MCP.

## Understand structure and requirements first

Connect a GitHub repository and ask in chat for feature documentation and an architecture diagram showing key dependencies. Include the requirements document so you can distinguish current behavior, intended behavior, and open decisions.

<Screenshot name="chat-review" alt="AI chat reading the Mamma document to explain record flow and review points" caption="Ask questions grounded in a document and narrow down what to verify." />

## Turn your review into an improvement document

Point to the parts of the diagram and feature description you want to change and explain why in chat. Agree on module reuse, edge cases, and tests, then record the result in a separate improvement document. If components appear to do the same job, inspect the source before deciding to consolidate them.

## Connect implementation to the next review

Connect Specify MCP to Claude Code or Codex and ask it to read the improvement document body. Implement and test in the coding agent, then push the changes. Existing documents and canvases linked to that repository and branch can be updated directly from the changes. Check the updated result and review any remaining differences.

## Example chat request

```text
Read the current reservation cancellation implementation and requirements. Explain the flow and exceptions.
Separate open decisions about the cancellation cutoff and screen states.
Record agreed changes, scope, acceptance criteria, and tests in an improvement document.
```

## Example request to the coding agent

```text
Read the reservation cancellation improvement document body through Specify MCP.
Compare it with the current code, plan the work, then implement and test the agreed scope.
Leave questions for policies the document does not establish.
```

<Note>When requirements change, ask the agent to read the same document again before implementation. MCP works through calls made by the coding agent. Request document reading and implementation in Claude Code or Codex, and use Specify chat to prepare the agreed document.</Note>
