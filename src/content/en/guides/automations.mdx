Keep linked documents and architecture canvases current when code reaches GitHub. Automatic updates are configured through the repositories connected to each document or canvas.

## Start automatic updates

1. [Connect GitHub](/en/guides/github) and create a document or canvas.
2. In the content, open **Connections** → **Manage connections** → **Event connections** and check the repository.
3. The next push to the displayed default branch triggers analysis of relevant changes.

Connect documents and canvases separately. Multiple outputs can use the same repository, and one output can be linked to several repositories.

## What a run does

The agent checks the diff, the current branch, and the existing content, then edits relevant parts directly. It can preserve the document when the relevant information is already current. For canvases, it updates related elements in the existing design.

With consecutive pushes, a newer run may replace an earlier one. Check that the final result matches the current code.

## Check run results

Open **Connections** → **Run history** to view execution status and analysis coverage in the inbox. Also inspect the saved document or canvas. Use document history to inspect and revert AI changes.

## Pause or disconnect

The agent editing lock stops automatic updates while allowing people to edit. To stop reflecting future pushes, uncheck the repository under **Event connections**.

If an update does not run, check GitHub status, the owner's GitHub usage setting, repository access, and content write permissions. See [Manage connections](/en/guides/automation-settings).
