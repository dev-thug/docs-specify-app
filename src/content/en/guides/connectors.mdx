Connectors let AI reference information from external services and let you hand some tasks to the agent. Manage connectors under **Settings** → **Tools & skills** → **Connectors**. You can also get there from **Skills & connectors** in the sidebar account menu.

<Screenshot name="tools-hub" alt="The Connectors tab in Tools & skills, with GitHub, Notion, Slack, Jira, Google, and Linear cards and an Add custom MCP server button" />

## Supported services

| Service | Description |
| --- | --- |
| **GitHub** | Code collaboration platform: repository code, issues and PRs, commit history |
| **Notion** | Docs and database workspace |
| **Slack** | Team messenger |
| **Jira** | Atlassian issue tracker |
| **Linear** | Issue tracking tool |
| **Google** | Combined Gmail, Calendar, and Drive integration |

Find the connector you want with the **All · Connected · Available · Needs attention** filters at the top of the list, the categories, and **Search apps**.

## Connect a service

<Steps>
  <Step title="Open the connector">
    Select the card for the service you want to connect to open its details. Check **Data the agent reads** and **Tasks you can delegate to the agent** first.
  </Step>
  <Step title="Connect to the workspace">
    Select the **Connect** button under **Connect to workspace**, then allow access on the service's screen. Once connected, members and the agent can use it together.
  </Step>
  <Step title="Check the status">
    Once connected, the card changes to **Connected**. If authentication expires, **Reconnect needed** appears; select **Reconnect** to authenticate again.
  </Step>
</Steps>

<Screenshot name="connector-github" alt="The GitHub connector details with a Connect to workspace button, About, Data the agent reads, and Tasks you can delegate to the agent" />

<Note>
  Only workspace admins can connect connectors. Organization GitHub repositories connect after a GitHub organization admin approves.
</Note>

## Slack advanced settings

After you connect Slack, you can specify **Channels the agent can search** and **Channels to exclude from search** under **Advanced settings**. Only messages in public channels are searched.

## Custom MCP servers

You can connect tools that aren't in the list directly as MCP servers.

1. Select **Add custom MCP server**.
2. Enter the **Server URL**, **Namespace**, and **Display name**.
3. Choose an **Authentication** method and, if needed, enter a **Header name** and **Secret**.
4. Check the consent that you trust the server, then save.

<Warning>
  A custom MCP server becomes an external tool the agent calls. Add only servers you trust, and use a secret with the minimum permissions needed.
</Warning>

## Disconnect

You can remove the connection from the connector details. Once removed, the agent no longer reads information from that service.
