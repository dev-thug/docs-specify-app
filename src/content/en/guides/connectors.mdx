Connectors bring external information and tools into Specify. Service account connections and your AI access preferences are managed separately.

## Open connectors

Open **Tools** → **Connectors** to see services and their connection status. Cards are available for GitHub, Notion, Slack, Jira, Linear, Gmail, Google Calendar, and Google Drive. Google services share one Google connection.

In service details, check the data the agent reads and the tasks it can handle. Read, search, and write capabilities vary by service.

## Account connections and AI access

1. A user with connection management permissions selects the service's **Connect** action.
2. Authorize the account and access scope on the service, then return to Specify.
3. Enable **Agent access** so the agent can use the connected data and tools.

After connecting an account, enable your AI access so the agent can use the service. Use **Reconnect** if authentication expires. Administrators manage workspace connections, while each user's AI access preferences apply to their use.

## GitHub and Slack scope

GitHub access includes only repositories allowed for the app. Organization policy may require approval. After connecting the account, configure push updates [for each output](/en/guides/automation-settings).

Slack advanced settings let you allow or exclude search channels. If both lists are empty, all public channels are searched; the allowlist takes precedence.

## Custom MCP servers

Administrators can add custom MCP servers. Enter an HTTPS server URL, namespace, display name, and authentication mode, and put required secrets in the connection form. Review the server and its tools, then confirm trust to register it.

The tool list is pinned at registration. When the server changes its tools, preview and apply the changes through tool refresh. Secrets are stored without being displayed again. Re-enter the required value in the connection form when refreshing.

## Stop usage or remove a connection

Turn off your AI access to stop the agent from using a connection. Removing the connection requires reconnecting before it can be used again. For GitHub-linked content, this also affects automatic updates; check **Connections** in the related documents and canvases.
