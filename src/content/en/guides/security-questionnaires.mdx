Prepare security questionnaire drafts using current policies and operational evidence. Organize items needing confirmation as questions for the responsible owners to support review and follow-up.

## Prepare the sources

Prepare the customer questions, current security and privacy policies, operational evidence, and previous answers. Mark reference dates, applicable services, and retired sources. Exclude sensitive customer or account information and secrets.

## Organize answers and evidence by question

Ask in chat for a table with a short answer, source document, scope, and verification status for each question. Update previous answers against current policies. When further evidence is needed, check source access and search scope, and verify certification status through official certificates or the responsible owner.

## Review and follow up

A security owner verifies the answers against actual operations before transferring them to the customer form and submitting them. Record the current status of capabilities and procedures that need work, and organize the follow-up in an improvement document. For code changes, the coding agent can read that document over MCP to review the implementation scope.

## Example chat request

```text
Read the customer security questions, current policies, and previous answers.
Create a table: question / draft answer / source document / scope / verification status.
Mark conflicting sources or missing operational evidence for owner review.
Do not claim unverified certifications or controls are held or complete.
```

<Note>Use this workflow to prepare answers for review, then transfer the approved answers to the customer form and submit it. For certification documentation and expert review, check the relevant preparation path and support scope at [Specify certification support](https://certify.specify.app).</Note>
