Work with documents and canvases in the same Specify workspace. Explain features and evidence in documents, then review components and data flows on a canvas. You can edit AI-created results and refine them with your team.

## Create and edit documents

Use **New File** in the explorer or ask the agent to write a document in chat. Rename the title and type in the body; changes save automatically. Use Markdown input for headings and lists, or type `/` on an empty line to open the block menu.

Choose headings, lists, quotes, code blocks, tables, images, callouts, or toggles for your content. Put API names and code examples in code formatting to keep them clear.

## Check save status

Watch the automatic save status. If **Not saved** appears, select **Retry save**. Unsaved content may exist only on this device. Copy anything you need before closing the tab or reloading.

Changes to your permissions or a document restoration by another person may require a reload. Preserve local edits first, then follow the on-screen instructions.

## Review architecture on a canvas

Ask the agent to create an architecture canvas from a repository, then open the result. Inspect components and connectors and edit their layout and descriptions. When requesting changes to an existing canvas, specify what to change and which elements to preserve.

Review dependencies and system boundaries by comparing document descriptions with connection directions on the canvas. If saving fails, retry and download a draft if needed.

## Improve a canvas from the bottom composer

Open a canvas to use **Ask to edit this canvas…** at the bottom. Select shapes or connections and ask, “Improve only these labels and layout; preserve the other connections.” See the [canvas guide](/en/guides/canvas) to draw and refine architecture through conversation.

## AI change history and editing lock

Inspect and revert AI edits in document history. Lock agent editing while reviewing or refining content; people can continue editing.

If another collaborator has changed the same object, reverting may be restricted to preserve their work. Check the current content and edit only the necessary parts.

## Link a repository

Check repositories and branches under **Connections** in each document and canvas. Owners configure automatic updates through **Manage connections** → **Event connections**. Relevant changes from subsequent pushes are applied directly, so review the inbox and change history afterward.

See [Create documents and canvases](/en/guides/doc-projects) and [Manage connections](/en/guides/automation-settings).
