Skills describe when and how an agent should perform a task. Open **Tools** → **Skills** to inspect built-in and workspace skills.

## Built-in and workspace skills

Built-in skills cover code analysis, diagram creation, document writing, and source evidence. They are always enabled. Built-in skills are available for reading. Add a workspace skill for instructions tailored to your team.

Administrators create or import workspace skills. Search the list, filter by source or enabled state, and toggle usage as needed. Members can read the list and skill contents.

## Create a skill

Select **New skill** to write a skill or upload a zip. `SKILL.md` contains its name, description, and instructions. Describe when to use it in the description, and put procedures and completion criteria in the instructions.

Place `SKILL.md` at the zip root or inside a single top-level folder. Include reference material as text files. Check format errors and duplicate-name notices before saving.

## Import from GitHub

Under **Import from GitHub**, enter a public repository URL, `owner/repo`, or a folder URL and scan it. Review discovered skills and compatibility, then select the ones to import.

Imported skills are pinned to a commit. Review instruction and tool compatibility in the import screen. Script execution is unsupported, so skills that require scripts can use part of their instructions. These skills are imported disabled; review their compatibility before enabling them.

## Updates and versions

Use **Check for updates** in skill details to check upstream changes. Review the changes and apply the source update or keep your app edits. Save or revert any unsaved changes first.

Restoring an earlier version through **Version history** creates a new version with that content and preserves the history.

## Use skills in conversations

The agent can select skills based on their usage conditions. Skills that allow user invocation can be selected with `/` in chat. Conversations show the skills used and references read. Review imported instructions before enabling them, since they may be used across conversations.

External service access is configured separately. Set up accounts and AI access through [connectors](/en/guides/connectors).
