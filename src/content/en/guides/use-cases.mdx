## Review every draft the same way

1. <strong>Set the scope.</strong> Name the source files, product version, time period, and repository commit.
2. <strong>Check the original evidence.</strong> Open source material instead of relying on search snippets. If a source does not appear, check indexing and access.
3. <strong>Ask for a reviewable format.</strong> Request a table, comparison, announcement, or checklist with source IDs, review status, and unresolved items.
4. <strong>Compare the draft with the sources.</strong> Separate facts from suggestions. Keep items that need an owner unconfirmed until someone verifies them.

<Note>Connecting a service does not automatically index every external item. Check [knowledge search scope](/en/knowledge/rag) and each [connector's read scope](/en/guides/connectors). When reusing a generated answer, check its original evidence and date.</Note>
