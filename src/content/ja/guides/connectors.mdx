コネクターを接続すると、外部サービスの情報をAIが参照でき、一部の作業はエージェントに任せられるようになります。コネクターは、**設定** → **ツールとスキル** → **コネクタ**で管理します。サイドバーのアカウントメニューの**スキル・コネクタ**からも開けます。

## 対応しているサービス

| サービス | 説明 |
| --- | --- |
| **GitHub** | コード協業プラットフォーム — リポジトリのコード、イシュー・PR、コミット履歴 |
| **Notion** | ドキュメント・データベースワークスペース |
| **Slack** | チームメッセンジャー |
| **Jira** | Atlassianのイシュートラッカー |
| **Linear** | イシュートラッキングツール |
| **Google** | Gmail・カレンダー・ドライブの統合連携 |

一覧の上部にある**すべて・接続済み・利用可能・要対応**のフィルターとカテゴリ、**アプリを検索**で、目的のコネクターを探します。

## 接続する

<Steps>
  <Step title="コネクターを開く">
    接続するサービスのカードを押すと、詳細画面が開きます。まず、**エージェントが読むデータ**と**エージェントに任せられる作業**を確認してください。
  </Step>
  <Step title="ワークスペースに連携する">
    **ワークスペースに連携**の**連携**ボタンを押し、サービスの画面でアクセスを許可します。連携すると、メンバーとエージェントが一緒に使えるようになります。
  </Step>
  <Step title="状態を確認する">
    接続されると、カードが**接続済み**に変わります。認証の有効期限が切れると**再接続が必要**と表示されるので、**再接続**を押して再度認証します。
  </Step>
</Steps>

<Screenshot name="connector-github" alt="GitHubコネクターの詳細画面。ワークスペースに連携ボタン、紹介、エージェントが読むデータ、エージェントに任せられる作業の一覧がある" />

<Note>
  コネクターを接続できるのは、ワークスペースの管理者だけです。組織のGitHubリポジトリは、GitHub組織の管理者の承認後に接続されます。
</Note>

## Slackの詳細設定

Slackを接続すると、**詳細設定**で**エージェントが検索するチャンネル**と**検索から除外するチャンネル**を指定できます。検索の対象になるのは、公開チャンネルのメッセージだけです。

## カスタムMCPサーバー

一覧にないツールは、MCPサーバーとして直接接続できます。

1. **カスタム MCP サーバーを追加**を押します。
2. **サーバー URL**、**ネームスペース**、**表示名**を入力します。
3. **認証**方式を選び、必要に応じて**ヘッダー名**と**シークレット**を入力します。
4. サーバーを信頼することへの同意にチェックを入れて保存します。

<Warning>
  カスタムMCPサーバーは、エージェントが呼び出す外部ツールになります。信頼できるサーバーだけを追加し、シークレットには権限が最小限の値を使ってください。
</Warning>

## 接続を解除する

コネクターの詳細画面から連携を削除できます。削除すると、エージェントはそのサービスの情報を読み取らなくなります。
