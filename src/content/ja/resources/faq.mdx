## 始め方

### どの資料から始めますか？

ワークスペースに文書を書くかファイルをアップロードし、チャットで必要な資料を指定して質問します。GitHub、Notion、Slack などの外部サービスは接続後、必要に応じて検索します。

### チームメンバーにも設定が必要ですか？

メンバーは自分のアカウントで招待を受諾します。外部エディターを接続する場合は、各自のMCPアクセス権限が必要です。

## 文書の自動更新

### コードの変更はどう反映されますか？

文書やキャンバスに GitHub リポジトリとブランチを接続すると、そのブランチへの push をきっかけに既存の項目を更新します。現在の本文と最新ソースを読み、必要な変更を保存します。完了後は保存内容と編集履歴から更新結果を確認できます。

### 自動更新の後は何を確認しますか？

受信トレイと実行結果を確認し、実際の文書の変更を見ます。無関係な説明が維持されたか、値の変更や機能の削除が正しく反映されたか、引用が正確かを確認してください。[文書の自動更新](/ja/guides/review-proposals)を参照してください。

## AIと知識検索

### どのモデルを使えばよいですか？

小さな作業で同じ資料と依頼を比較し、事実、欠落、保存結果、利用量を確認します。[モデル選択ガイド](/ja/models/choosing)を参照してください。

### 必要な資料を検索で見つけるにはどうすればよいですか？

文書名や固有の用語で検索し、文書一覧と原文も確認してください。保存やアップロードの直後は、索引化の状態を確認してから再検索します。外部サービスの資料は、ワークスペースの索引とは別にコネクター検索を使います。[ワークスペースRAG](/ja/knowledge/rag)を参照してください。

### 規格を引用すれば提出可能な文書になりますか？

引用で根拠を確認し、条項・版・規範性・製品固有の資料を専門家とレビューして提出資料を仕上げます。規制適合性と認証は、該当する評価手続きで確認します。[標準文書ライブラリ](/ja/knowledge/standards)を参照してください。

## MCPと利用料金

### MCPでは何ができますか？

Claude Code や Codex などの外部エージェントがワークスペースの文脈を検索して読み取れます。書き込み権限と適切な役割があれば、文書やキャンバスも編集できます。[提供ツール](/ja/mcp/tools)を参照してください。

### 料金とサポートはどこで確認できますか？

最新の条件は[料金ページ](https://specify.app/pricing)、問い合わせは [support@specify.app](mailto:support@specify.app) をご利用ください。
