Specify の主な用語を説明します。

## 資料と作業

| 用語 | 意味 |
| --- | --- |
| ワークスペース | 文書、会話、メンバー、接続したツールを共有する作業範囲です。 |
| 文書 | 保存、編集、変更履歴の確認ができるテキスト資料です。 |
| キャンバス | 要素と接続で構造やアーキテクチャを表す資料です。 |
| リポジトリ接続 | 文書・キャンバスを GitHub リポジトリとブランチに接続し、コード変更を反映する設定です。 |
| 自動更新 | 接続したブランチへの push をきっかけに、既存文書やキャンバスを最新ソースに合わせる作業です。 |
| 受信トレイ | バックグラウンド作業の進捗と結果を確認する場所です。 |
| スレッド | エージェントとの会話の単位です。 |

## 知識とツール

| 用語 | 意味 |
| --- | --- |
| RAG | 検索した資料を根拠に回答を作る検索拡張生成です。 |
| 索引化 | 文書やファイルを検索可能な資料へ処理することです。 |
| 標準文書ライブラリ | 規格の条項と版を根拠として検索する知識ソースです。 |
| スキル | エージェントが特定の作業で従う指示です。 |
| コネクター | GitHub、Notion、Slack などの外部サービスへの接続機能です。 |
| MCP | 外部AIクライアントがツールや資料を使うための接続規約です。 |
| MCPトークン | 外部クライアントがワークスペースにアクセスする認証情報です。既定では読み取り専用です。 |
| リビジョン | 読み取りや編集を行った文書・キャンバスの版です。書き込み競合の確認に使います。 |
| 思考強度 | モデルの推論設定です。対応する段階はモデルとプランによって異なります。 |
| [GAP] | 追加の根拠や人の確認が必要な箇所を示します。 |
