Specify MCP は Claude Code、Codex、Cursor などの外部エージェントがチームの文書や資料を検索し、読み取るための接続です。Specify の内外で同じワークスペースの文脈を使えます。

## できること

エージェントは資料を検索して原文を読み、ドメイン用語、要求事項、決定を確認します。書き込み権限と適切な役割があれば、文書やキャンバスも編集できます。コードの実装は接続したコーディングエージェントに直接依頼し、そのエージェントで進捗と結果を確認してください。

## サーバーと認証

| 項目 | 内容 |
| --- | --- |
| サーバーURL | `https://mcp.specify.app` |
| 通信方式 | Streamable HTTP |
| 認証 | ワークスペースのトークン（Bearer）または OAuth |
| スコープ | `mcp:read` が既定、`mcp:write` は任意 |

## 接続と活用

**ツールとスキル** → **エディタ連携** でクライアントを選び、生成されたコマンドや設定を適用します。既定では読み取り専用で、書き込みが必要な場合だけ追加権限を許可します。

接続後は「この機能の要求事項と最近の決定を探して原文を読んで」と依頼してください。実装前に原文を読み、作業中に文書が変更されたら再度読んで現在の要求事項を確認します。

[クライアント別接続方法](/ja/mcp/connect)、[提供ツール](/ja/mcp/tools)、[アクセスポリシー](/ja/mcp/access)を参照してください。
