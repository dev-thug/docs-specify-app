Specify MCP は Specify エージェントと同じ作業空間・知識検索ツールを外部エージェントに提供します。利用可能なツールと入力は、クライアントの `tools/list` が返すスキーマに従います。

## 検索と読み取り

| ツール | 用途 |
| --- | --- |
| `list_files` | 文書やアップロードしたファイルのパスと現在のバージョンを確認します。 |
| `search_files` | 文書本文で文字列を探します。 |
| `read_file` | ファイル本文を読みます。`startLine`、`endLine` で範囲を指定できます。 |
| `knowledge_search` | 意味が関連する知識の断片を探します。 |
| `knowledge_grep` | 索引化された資料で正確な文字列を探します。 |
| `knowledge_status` | 知識資料の処理状態を確認します。 |
| `search_connectors` | 接続した外部サービスで資料を検索します。 |

知識・コネクターツールの提供は、接続したサービスとワークスペースの状態によって異なります。

## 文書とキャンバス

| ツール | 用途 |
| --- | --- |
| `create_document`、`write_document` | 文書の作成や本文の保存を行います。 |
| `edit_document` | 既存文書の指定した文字列を編集します。 |
| `list_document_history`、`read_document_revision` | 文書の履歴や以前の版を読みます。 |
| `revert_document` | 文書を以前の版に戻します。 |
| `create_canvas`、`read_canvas`、`edit_canvas` | キャンバスを作成、読み取り、編集します。 |

編集前に `read_file` または `read_canvas` で最新の内容を読んでください。書き込み時はスキーマが要求する `baseRevision` と位置のバージョンを渡します。競合した場合は再読込して編集します。`edit_document` の `oldText` は正確に1回だけ一致する必要があります。

## フォルダーとゴミ箱

`create_folder`、`move_entry`、`trash_entry`、`list_trash`、`restore_entry` でフォルダーと項目を管理します。項目を削除するツールは、クライアントに破壊的な操作として通知されます。

## 権限と制限

読み取りは `mcp:read`、文書・キャンバス・構造の変更は `mcp:write` が必要です。書き込みにはワークスペースの役割と現在のアクセスポリシーも適用されます。MCPから除外した文書・フォルダーとその配下は外部アクセスの対象外です。

MCP はワークスペース資料の検索、読み取り、許可された編集を提供する接続です。コードの実装を進める際は、外部コーディングエージェントに文書の読み取りと実装を直接依頼してください。[トークンとアクセスポリシー](/ja/mcp/access)を参照してください。
