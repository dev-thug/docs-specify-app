Specify MCPサーバーは5つのツールを提供します。読み取りツールには`mcp:read`、書き込みツールには`mcp:write`の権限スコープが必要です。正確な入力スキーマは、クライアントが`tools/list`で受け取るJSON Schemaが基準です。

## ツール一覧

| ツール | 権限スコープ | 機能 |
| --- | --- | --- |
| `search` | `mcp:read` | ワークスペースのドキュメントを意味・タイトルで検索し、有効化された外部コネクタの結果を出典ごとにまとめて返します。 |
| `read_document` | `mcp:read` | テキスト・PDFドキュメントの本文全体または一部の範囲を読み取ります。 |
| `browse` | `mcp:read` | ドキュメントツリー、最近のドキュメント、タイトル検索でワークスペースを探索します。 |
| `create_document` | `mcp:write` | Markdownの本文で新しいドキュメントを作成します。 |
| `update_document` | `mcp:write` | ドキュメント内の特定のテキストを完全一致で見つけて置き換えるか、本文の末尾に追記します。 |

## search

作業に必要なドキュメントを探すときに使います。

| 入力 | 説明 |
| --- | --- |
| `query` | 検索語 |
| `topK` | 任意。返す結果の数（1–25） |

## read_document

検索や探索で見つけたドキュメントを読み取ります。長いドキュメントは範囲ごとに分けて読み取れます。

| 入力 | 説明 |
| --- | --- |
| `nodeId` | 読み取るドキュメントのID |
| `around`, `offset`, `limit`, `page` | 任意。読み取る範囲を指定します。 |

## browse

| 入力 | 説明 |
| --- | --- |
| `mode` | `tree`（ドキュメントツリー）、`recent`（最近のドキュメント）、`search`（タイトル検索）のいずれか |
| `query` | 任意。`search`モードの検索語 |
| `limit` | 任意。返す項目の数 |

## create_document

| 入力 | 説明 |
| --- | --- |
| `title` | ドキュメントのタイトル |
| `content` | Markdownの本文 |
| `parentNodeId` | 任意。ドキュメントを作成する親フォルダ |

## update_document

| 入力 | 説明 |
| --- | --- |
| `nodeId` | 編集するドキュメントのID |
| `search` | 任意。置き換えるテキスト（完全に一致する必要があります） |
| `replace` | 置き換える内容。`search`がない場合は本文の末尾に追記します。 |

アップロードしたファイルのドキュメントは編集できません。

## 権限と制限

- すべてのツール呼び出しで、毎回トークン、ワークスペースのメンバーシップ、権限スコープ、管理者のアクセス方針、呼び出し上限を確認します。メンバーが退会したりトークンが失効したりすると、既存のトークンではデータにアクセスできなくなります。
- 書き込みツールには編集者以上のワークスペースでの役割が必要で、ワークスペースへの書き込みがロックされている場合は実行されません。
- MCPへの公開から除外されたドキュメント・フォルダとその配下のパスは、検索・読み取り・編集の結果に表示されません。
- 入力や権限の問題でツールの実行に失敗した場合は、エージェントが読み取って修正できる説明とともにエラー結果を返します。
