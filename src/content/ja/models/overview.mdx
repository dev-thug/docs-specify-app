Specifyは、Anthropic ClaudeとOpenAI GPT系の6種類のモデルを提供しています。チャットの入力欄で会話ごとにモデルを選び、ワークスペースの設定でオートメーションとドキュメント生成に使う既定のモデルを決めます。

## モデルの比較

| モデル | 提供元 | 利用できるプラン | コンテキスト | 最大出力 | 入力 / 出力の単価（100万トークンあたり） |
| --- | --- | --- | --- | --- | --- |
| **Claude Opus 4.6** | Anthropic | プロ以上 | 100万 | 128K | $5.00 / $25.00 |
| **Claude Sonnet 4.6** | Anthropic | プロ以上 | 100万 | 64K | $3.00 / $15.00 |
| **Claude Haiku 4.5** | Anthropic | 無料を含むすべて | 20万 | 64K | $1.00 / $5.00 |
| **GPT-6 Sol** | OpenAI | プロ以上 | 105万 | 128K | $2.00 / $10.00 |
| **GPT-5.6 Terra** | OpenAI | プロ以上 | 105万 | 128K | $2.00 / $12.00 |
| **GPT-6 Luna** | OpenAI | 無料を含むすべて | 105万 | 128K | $0.10 / $0.50 |

- 単価は提供元の標準単価（2026年9月時点で確認）です。Specifyは、この単価で計算した実際のコストをワークスペースのAI予算から差し引きます。詳しくは[使用量とAI予算](/ja/models/usage)を参照してください。
- すべてのモデルが、ツール呼び出し（ナレッジ検索、ドキュメントの読み取り・書き込みなど）と並列ツール呼び出しに対応しています。
- 新しい会話の既定のモデルは**GPT-6 Luna**です。

## 思考の強度

すべてのモデルで、**思考の強度**を**オフ**、**低**、**中**、**高**、**エクストラ**、**最大**の6段階で調整できます。強度を上げると回答する前により深く推論しますが、応答が遅くなり、トークンを多く消費します。

| 段階 | 推論に使う最小トークン |
| --- | --- |
| オフ | 推論なし |
| 低 | 約1,000 |
| 中 | 約4,000 |
| 高 | 約16,000 |
| エクストラ | 約32,000 |
| 最大 | 約60,000 |

<Note>
  無料プランでは、思考の強度は**オフ**に固定されます。モデルを変更すると、現在の思考の強度は新しいモデルが対応する範囲に合わせて調整されます。
</Note>

## モデルを選ぶ場所

| 場所 | 適用範囲 |
| --- | --- |
| チャットの入力欄のモデルボタン | 現在の会話全体。応答中は変更できません。 |
| **設定** → **ワークスペース** → **一般** → **デフォルトAIモデル** | このワークスペースのオートメーション |
| **設定** → **ワークスペース** → **一般** → **ドキュメント生成モデル** | ドキュメント自動化（プロジェクトの生成・自動更新） |

プランで利用できないモデルはメニューに鍵のアイコンで表示され、選択するとプランのアップグレードの案内が表示されます。リクエストしたモデルが、知らないうちに別のモデルに置き換えられることはありません。
