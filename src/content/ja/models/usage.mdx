SpecifyのAI使用量は、**ワークスペースごとの月間AI予算**で管理されます。チャット、ドキュメント生成、オートメーション、ナレッジ検索など、AIを使うすべての作業が同じ予算を使用します。

## 使用量を確認する

**設定** → **プラン・請求** → **利用状況**で、今月の利用期間とAI予算の使用率を確認します。サイドバーのアカウントメニューにも使用率が表示されます。

<Screenshot name="settings-usage" alt="利用状況の画面。今月の利用期間、ドキュメント無制限、AI予算の使用率バーが表示されている" />

- 使用量は現在のワークスペースを基準とします。個人ワークスペースとチームワークスペースの予算はそれぞれ別です。
- 使用量は、毎月の利用期間が終わるとリセットされます。

## 使用量の計算方法

各リクエストは、使用したモデルのトークン単価で実際のコストを計算し、予算から差し引かれます。クレジットの倍率やリクエスト回数ではなく、**実際のトークン使用量**が基準です。

- 高価なモデルほど、思考の強度が高いほど、長いドキュメントを多く読むほど、使用量は大きくなります。モデルの利用範囲は[モデルの概要](/ja/models/overview)、最新料金は[料金ページ](https://specify.app/ja/pricing)を参照してください。
- 同じ内容を繰り返し読むときはキャッシュが適用され、入力のコストが大幅に下がります。
- GPT系のモデルでは、1回のリクエストの入力が27万2,000トークンを超えると、そのリクエストの単価が上がります（入力2倍、出力1.5倍）。
- Claude Haiku 5.5も、1回の入力（キャッシュを含む）が10万トークンを超えると長文の割増料金が適用されます。
- ナレッジ検索も少量の使用量を消費します。

## プランごとの予算

上位のプランほど、月間AI予算が大きくなります。

| プラン | AI使用量 |
| --- | --- |
| 無料 | 基本的なAI利用 |
| プロ | 無料プランより余裕のあるAI使用量 |
| マックス | プロプランの5倍のAI使用量 |
| チーム | シートごとの予算をチームで一緒に使う共有プール |
| エンタープライズ | 組織に合わせてカスタマイズ |

正確な上限と価格は、[料金ページ](https://specify.app/ja/pricing)をご確認ください。

## 警告とチャージ

- 予算の70%と90%を使うと、警告が表示されます。
- 予算を使い切ると**AI予算が枯渇しました**のバナーが表示され、**$5チャージ**で使用量をチャージできます。チャージしたクレジットは、基本の予算を使い切った後にのみ差し引かれます。
- 残高があっても、1回の実行にはラウンド数・時間の制限があるため、作業が一部しか完了しないことがあります。

## 使用量を節約する方法

1. **基本はGPT-6 Lunaで。** 短いリクエストや小さな修正から試し、結果を確認してください。
2. **必要なときだけ思考の強度を上げます。** 対応する低い段階から始め、結果が不十分なら調整してください。説明の深さ、所要時間、使用量を併せて比較してください。
3. **質問の範囲を絞ります。** ドキュメント名や`@`メンションで対象を指定すると、不要な検索と読み取りが減ります。
4. **長い会話は新しく始め直します。** 会話が長くなるほど、リクエストのたびに読み込む内容が増えます。
5. **オートメーションの頻度を見直します。** 毎日実行する必要のないオートメーションは、週単位に変更します。
