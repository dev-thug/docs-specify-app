# RelayDesk Demo 프로젝트 인수인계 메모

문서 ID: RD-HANDOVER-01. 기준일: 2026-10-06. 상태: 가상 프로젝트 검토 자료.

이 자료는 시연용이다. 담당자는 실명이 아닌 역할로 적는다. 이 예제의 저장소에는 업무 목록 CSV 내보내기 라이브러리와 테스트만 있으며, 실제 고객 서비스·서버·DB는 없다.

## 요청과 현재 범위

| 요청 | 현재 확인할 상태 |
| --- | --- |
| 업무 목록 CSV 내보내기 | 1.4 시연 버전에 구현. 코드와 테스트로 다시 확인할 것 |
| 최대 10,000건 내보내기 | 기획 단계의 요청. 현재 구현 한도와 동일하다고 가정하지 말 것 |
| 첨부파일 ZIP 다운로드 | 후속 검토 항목. 이번 버전의 완료 기능으로 소개하지 말 것 |
| 모든 역할에서 내보내기 | 승인된 범위가 아님. 소유자·편집자만 허용하고 뷰어는 거부 |

## 결정 기록

CSV의 첫 행은 id, title, status다. 스프레드시트에서 수식으로 해석될 수 있는 텍스트는 문자열로 내보낸다. 제목의 쉼표·따옴표도 CSV 형식에 맞게 처리한다. 이 구현을 인증·암호화·감사로그가 포함된 전체 서비스라고 설명하면 안 된다.

## 실행과 담당 역할

- Node.js 24 이상. 설치할 외부 의존성은 없다. `npm test`로 테스트, `npm run demo`로 합성 데이터를 사용한 실행 예제를 확인한다.
- 개발 담당: exportTasks 동작과 테스트 범위 확인.
- 제품 담당: 10,000건 요청 및 ZIP 기능의 후속 일정 결정.
- 운영 담당: 실제 서비스의 배포·모니터링·복구 절차를 별도 문서화.
- 고객지원 담당: 현재 한도와 역할 제한을 FAQ에 반영.

## 인수인계에서 남길 미확인 사항

실제 배포 환경, 접근 권한 발급 절차, 장애 대응 연락망, 복구 시험 기록, 처리량 측정 결과는 이 자료에 없다. 담당자·일정·완료 여부를 만들어 쓰지 않는다.
