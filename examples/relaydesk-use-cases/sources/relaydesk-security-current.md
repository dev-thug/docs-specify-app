# RelayDesk Demo 보안·운영 정책 v2

문서 ID: RD-SEC-02. 기준일: 2026-10-06. 상태: 현행 시연 자료.

이 자료는 Specify 활용사례 재현을 위한 가상 제품의 정책입니다. 실제 Specify의 보안·인증·계약 조건을 설명하지 않습니다. 실제 고객·개인정보·비밀은 포함하지 않습니다.

## 현행 답변 근거

| 항목 | 가상 제품의 승인된 설명 |
| --- | --- |
| 전송 구간 | TLS 1.2 이상 사용 |
| 저장 데이터 | 저장소 암호화 AES-256 사용 |
| 데이터 위치 | 서비스 데이터의 기본 저장 위치는 서울 리전 |
| 계정 권한 | 소유자·편집자·뷰어. CSV 내보내기는 소유자와 편집자만 가능 |
| 삭제 요청 | 운영 데이터는 삭제 요청 후 30일 이내 삭제. 백업 사본은 최대 35일의 보관 주기 후 만료 |
| SSO | 초대받은 파일럿 고객에게만 제공. 모든 고객에게 일반 제공되는 기능이 아님 |
| SOC 2 | 완료된 감사 보고서·인증 보유를 확인할 자료가 없음. 보유했다고 답변하지 않음 |
| 하위 처리업체 | 고객 제공용 확정 목록이 이 자료에 없음. 계약 담당자의 별도 확인 필요 |

## 이전 자료와의 관계

RD-SEC-01의 "삭제 요청 후 90일" 답변은 이 v2 문서가 대체한다. 답변에 과거 90일을 현재 정책으로 사용하지 않는다. 운영 데이터 삭제와 백업 만료를 하나의 기간으로 합치지 않는다.

## 고객 답변 검토

모든 답변은 제출 전 담당자가 확인한다. 확인되지 않은 사항은 "담당자 확인 필요"로 남기고, 보안 통제나 감사 결과를 추정하지 않는다.
