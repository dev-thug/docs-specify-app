# RelayDesk Demo 기존 고객 FAQ — 1.3 기준

문서 ID: RD-FAQ-13. 기준 버전: 1.3. 현행 여부: 1.4 변경 자료와 대조해 갱신할 시연 자료.

이 문서는 가상 제품의 과거 FAQ다. 실제 Specify 기능을 설명하지 않는다.

## 업무 목록을 파일로 내보낼 수 있나요?

1.3에서는 업무 목록 CSV 내보내기를 제공하지 않습니다.

## 뷰어도 내용을 변경할 수 있나요?

뷰어는 업무 내용을 변경할 수 없습니다.

## 첨부파일을 ZIP으로 받을 수 있나요?

제공하지 않습니다. 후속 검토 항목이며 출시 일정은 확정하지 않았습니다.

## SSO를 바로 사용할 수 있나요?

초대받은 파일럿 고객만 사용할 수 있습니다. 모든 고객의 일반 제공 기능이 아닙니다.
