# RelayDesk Demo 1.4 변경사항과 고객 안내 기준

문서 ID: RD-RELEASE-14. 기준일: 2026-10-06. 상태: 가상 제품 시연 버전의 안내 자료.

이 자료는 실제 서비스 출시 공지가 아니다. 날짜·기능·정책은 공개 활용사례를 위한 가상 시나리오다. 고객에게 발송하지 않고 검토용 초안을 만든다.

## 이번 버전에 포함된 변화

- 업무 목록을 CSV로 내보내는 기능을 추가했다.
- CSV 열은 id, title, status다. 첨부파일은 포함하지 않는다.
- 한 번에 최대 1,000건. 초과하면 줄여서 다시 시도하도록 안내한다.
- 소유자와 편집자만 가능하며, 뷰어는 권한 있는 담당자에게 요청해야 한다.
- 수식으로 해석될 수 있는 텍스트와 쉼표·따옴표를 안전하게 CSV 텍스트로 처리한다.

## 안내하지 않을 내용

- ZIP 첨부파일 다운로드는 이번 버전에 없다.
- 10,000건 지원은 기획 요청일 뿐 현재 한도가 아니다.
- SSO는 이번 CSV 변경과 무관하다. 정책상 초대된 파일럿 고객에게만 제공된다.
- 응답속도 개선 수치, 인증 획득, 모든 고객 무제한 제공을 주장할 근거는 없다.

## 독자별 작성 목적

제품 담당자는 변경 요약을 검토한다. 고객지원은 "누가 사용할 수 있나요", "몇 건까지 가능한가요", "첨부파일도 포함되나요"에 답하는 FAQ를 준비한다. 고객 안내문은 기술 구현명보다 사용자가 얻는 결과와 제한을 먼저 설명한다. 원문에 없는 UI 메뉴 경로는 만들지 않는다.
