# MedRelay Demo

의료기기 소프트웨어 개발 문서 작성 과정을 설명하기 위한 **가상 기기 데이터 수집 예제**입니다. 실제 의료기기, 진단 소프트웨어 또는 임상 시스템이 아니며 환자 데이터를 포함하지 않습니다. 데이터는 모두 합성 입력입니다.

## 구현 범위

1. 합성 기기 패킷의 기기 ID, UTC 시각, 일련번호, 신호 표본 배열을 검증합니다.
2. 기기별 일련번호가 증가하는 패킷만 메모리 버퍼에 저장합니다.
3. 최근 패킷과 수신 건수, 보관 건수, 통신 데이터의 신선도를 요약합니다.
4. 저장된 합성 패킷의 메타데이터를 CSV로 내보냅니다. 원시 신호 값은 CSV에 포함하지 않습니다.

의료적 정상/비정상 판정, 임상 경보, 진단, 치료 제어, 환자 식별, 네트워크 서버, 영구 저장 기능은 구현하지 않았습니다. 신선도 표시는 통신 데이터가 오래됐는지 표시하는 기술적 상태이며 임상적 경보가 아닙니다.

## 실행

Node.js 24 이상에서 `npm ci`, `npm test`, `npm run demo`를 순서대로 실행합니다. 외부 계정이나 자격 증명은 필요하지 않습니다.

## 코드 지도

| 파일 | 책임 |
| --- | --- |
| `src/packet.js` | Zod 스키마와 입력 패킷 검증 |
| `src/recorder.js` | 일련번호 검사, 메모리 버퍼, 최근 수신 상태 |
| `src/export.js` | CSV 메타데이터 내보내기 |
| `src/demo.js` | 합성 입력을 사용한 실행 예제 |
| `test/recorder.test.js` | 입력 검증, 순서 검사, 보관 한도, 신선도 및 내보내기 테스트 |

## 문서 검토에 필요한 미확정 정보

이 예제에는 제조사가 승인한 의도된 사용, 실제 사용자·환자군, 의료기기 해당 여부, 안전 등급, 위험 수용 기준, 적용 규격·판, 임상적 성능 요구, 위험 분석, 사용성 평가, SOUP 이상 목록 평가, 승인 기록이 없습니다. 생성 문서에서 이 항목은 미확정 또는 `[GAP]`으로 남겨야 합니다.

자동 테스트는 이 예제 구현의 동작을 확인하며 의료기기 검증 또는 임상 평가의 증거가 아닙니다. 테스트 파일 존재를 실행 결과나 승인된 시험 프로토콜로 오인하지 마세요.

## 외부 소프트웨어

런타임 의존성은 Zod 3.25.17이며 `src/packet.js`에서 사용합니다. 정확한 전이 의존성과 라이선스 근거는 `package-lock.json` 및 배포 패키지에서 확인합니다. 알려진 이상 평가와 안전 영향 평가는 수행하지 않았습니다.
